# 固件上传功能使用说明

## 修复概述

固件上传功能已修复，现在可以正常工作。修复使用了 `pyautogui` 和 `pyperclip` 库来处理Windows原生文件选择对话框。

## 使用前准备

### 1. 确保依赖已安装

依赖已添加到 `requirements.txt`，如果尚未安装：

```bash
pip install pyautogui>=0.9.50 pyperclip>=1.8.0
```

或者重新安装所有依赖：

```bash
pip install -r requirements.txt
```

### 2. 准备固件文件

将固件文件放置在以下目录：

- **旧版本固件**: `E:\GIT\ROUTER_TEST\docs\upload\old\`
- **新版本固件**: `E:\GIT\ROUTER_TEST\docs\upload\new\`

## 测试方法

### 方法1: 单元测试（推荐用于验证）

运行单元测试脚本验证上传功能：

```bash
python test_firmware_upload.py
```

**注意**：此测试只验证文件上传，不会实际执行升级，避免路由器重启。

### 方法2: 完整稳定性测试

通过Web界面运行完整的固件升级稳定性测试：

1. 启动测试框架：
   ```bash
   python app.py
   ```

2. 浏览器访问：http://localhost:5000

3. 选择测试用例：**多设备反复升级稳定性测试**

4. 点击"开始测试"

## 测试期间注意事项

⚠️ **重要提示**：

1. **不要操作键盘和鼠标**
   - 测试期间会自动操作文件选择对话框
   - 手动操作可能导致测试失败

2. **确保测试机器焦点**
   - 文件选择对话框必须是当前活动窗口
   - 不要切换到其他应用程序

3. **单台电脑运行**
   - 不支持并发测试
   - 多个测试会冲突

4. **Windows系统**
   - 当前仅支持Windows
   - Linux/macOS需要单独适配

## 工作原理

```
1. Selenium点击"浏览"按钮
   ↓
2. Windows文件选择对话框自动打开
   ↓
3. pyperclip复制文件路径到剪贴板
   ↓
4. pyautogui模拟键盘操作：
   - Ctrl+V: 粘贴文件路径
   - Enter: 确认选择
   ↓
5. 文件路径自动填充到页面输入框
   ↓
6. 点击升级按钮，开始固件升级
```

## 故障排查

### 问题1: 缺少依赖库

**错误信息**:
```
❌ 缺少依赖库: pyautogui 或 pyperclip
```

**解决方法**:
```bash
pip install pyautogui pyperclip
```

### 问题2: 文件选择失败

**可能原因**:
- 文件对话框打开太慢
- 键盘操作被拦截

**解决方法**:
1. 检查是否有其他程序占用文件对话框
2. 确保没有安全软件拦截键盘操作
3. 增加延时（修改 `core/router_client.py` 中的 `time.sleep(2)`）

### 问题3: 文件路径包含中文

**问题**: 部分系统可能不支持中文路径

**解决方法**:
- 将固件文件移动到纯英文路径
- 或者使用短路径（Windows短文件名）
