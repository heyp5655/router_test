### 5️⃣ 多进程文件上传冲突修复 (20:15 - 20:30)

**问题**: 两个进程同时操作文件对话框，路径重复输入
- 现象: `E:\...\32.3.0.7.bin\E:\...\32.3.0.7.bin`
- 原因: pyautogui操作全局键盘鼠标

**解决**:
- 使用 multiprocessing.Lock 串行化文件上传
- 同一时间只有一个进程操作文件对话框

**代码**:
```python
from multiprocessing import Lock
upload_lock = Lock()

with upload_lock:
    device_client.upload_and_upgrade_firmware(...)
```

**文件**:
- ✅ `test_cases/stability/multi_device_firmware_upgrade_stability_test.py`
- ✅ `docs/多进程文件上传冲突修复_20251202.md`
