## 🔧 技术实现

### 配置的端口字段

| 序号 | 字段名称 | 元素XPath | 描述 |
|------|---------|-----------|------|
| 1 | HTTP | `//*[@id="1_http_port"]` | HTTP服务端口 |
| 2 | HTTPS | `//*[@id="1_https_port"]` | HTTPS服务端口 |
| 3 | TELNET | `//*[@id="1_telnet_port"]` | TELNET服务端口 |
| 4 | SSH | `//*[@id="1_ssh_port"]` | SSH服务端口 |
| 5 | FTP | `//*[@id="1_ftp_port"]` | FTP服务端口 |

### 测试流程（带弹窗检测）

```python
1. 跳转到防火墙Security页面
   - URL: #network/firewall/security
   - 点击Security子标签
   - 刷新页面确保元素加载

2. 遍历5个端口字段:
   for field in [HTTP, HTTPS, TELNET, SSH, FTP]:
       for port in ports:
           a. 定位端口输入框
           b. 清空输入框
           c. 输入端口号
           d. 点击保存按钮
           e. ⚠️ 等待3秒检测alert弹窗
           f. 判断测试结果:
              - 有弹窗 → ✅ 测试通过（冲突检测生效）
              - 无弹窗 → ❌ 测试失败（冲突检测失效）
           g. 点击OK关闭弹窗（如果有）
           h. 记录测试结果

3. 统计并输出测试报告
```

### 弹窗检测机制（核心）

```python
# 关键代码：检查是否有冲突弹窗
has_popup = False
try:
    # 尝试检测alert弹窗（等待3秒）
    alert = WebDriverWait(self.driver, 3).until(
        EC.alert_is_present()
    )
    has_popup = True
    alert_text = alert.text
    print(f"  ✅ 检测到冲突弹窗: {alert_text}")
    # 点击OK关闭弹窗
    alert.accept()
    print(f"  已点击OK关闭弹窗")
except TimeoutException:
    # 没有弹窗 - 这是测试失败的情况！
    has_popup = False
    print(f"  ❌ 未检测到冲突弹窗（应该有弹窗）")

# 判断测试结果
if has_popup:
    stats["passed"] += 1  # ✅ 测试通过
else:
    stats["failed"] += 1  # ❌ 测试失败
```

## 📝 使用示例

### 在测试用例中使用

```python
from test_cases.base_test import BaseTest

class FirewallSecurityConflictTest(BaseTest):
    def execute(self):
        # 定义保留端口列表
        reserved_ports = [22, 53, 80, 443, 1701, 9001]

        # 调用测试方法
        stats = self.router_client.configure_firewall_Security_ports(reserved_ports)

        # 判断测试结果
        if not stats["success"]:
            failed_count = stats["failed"]
            raise Exception(
                f"端口冲突检测测试失败！{failed_count}个端口未触发冲突提示"
            )

        print("✅ 所有端口都正确触发了冲突检测")
        return stats
```

### 独立脚本使用

```python
from core.router_client import RouterClient

router = RouterClient("192.168.1.1", "admin", "admin")
router.login_web()

# 测试保留端口
reserved_ports = [22, 53, 1701, 9001, 68, 500, 4500, 123]
stats = router.configure_firewall_Security_ports(reserved_ports)

print(f"测试通过率: {stats['passed'] / stats['total'] * 100:.1f}%")

if not stats["success"]:
    print("失败的端口:")
    for field, port in stats["failed_details"]:
        print(f"  - [{field}] 端口 {port}")

router.close()
```
