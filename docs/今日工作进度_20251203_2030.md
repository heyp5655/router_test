## 已完成的修复

### 1. ✅ 串口烧录后登录时机误判修复 (19:55 - 20:10)

**问题**: `ifconfig Bridge0 192.168.50.17` 命令未生效，导致Web无法登录

**根本原因**:
- 设备重启后，串口缓冲区残留大量启动日志
- `login()` 方法读取缓冲区，检测到旧的 `root@` 提示符
- 误判为"已登录"，跳过用户名密码输入
- 实际设备在 `ROUTER login:` 提示符等待

**修复方案**:

1. **优先检查 login: 提示符** (`utils/serial_client.py` 第293-306行)
```python
# 修改前: 只检查 root@
if "root@" in output and "#" in output:
    return True

# 修改后: login: 优先级更高
if "login:" in output:
    # 继续执行登录流程
elif "root@" in output and "#" in output:
    return True
```

2. **烧录后清空串口缓冲区** (`utils/serial_client.py` 第603-625行)
```python
def login_after_flash(self) -> bool:
    # 清空串口缓冲区（丢弃启动日志）
    if self.serial.in_waiting > 0:
        old_data = self.serial.read(self.serial.in_waiting)
        print(f"清空了 {len(old_data)} 字节的启动日志")

    time.sleep(1)
    return self.login()
```

**文档**: `docs/串口烧录后登录时机误判修复_20251203.md`

### 3. ✅ 分屏显示中文乱码修复 (20:15 - 20:20)

**问题**: PowerShell窗口显示中文乱码

**根本原因**:
- PowerShell默认编码不是UTF-8
- `Get-Content` 未指定编码

**修复方案** (`utils/split_console.py` 第87-110行):

```python
# 设置PowerShell控制台编码为UTF-8
device1_cmd = [
    "powershell", "-NoExit", "-Command",
    f"[Console]::OutputEncoding = [System.Text.Encoding]::UTF8; "
    f"$host.ui.RawUI.WindowTitle='Device1 - COM7 -> 192.168.50.18'; "
    # ...
    f"Get-Content '{self.device1_log_path}' -Encoding UTF8 -Wait -Tail 0"
]
```

**关键改进**:
1. 设置控制台编码: `[Console]::OutputEncoding = UTF8`
2. 指定文件读取编码: `-Encoding UTF8`
3. 窗口标题改为英文（避免标题栏乱码）

### 4. ✅ 串口重复打开问题修复 (20:20 - 20:30)

**问题**: 循环995次后串口打开失败

**根本原因**:
- 测试用例先调用 `serial_client.open()` 打开串口
- 再调用 `flash_old_firmware()`
- 导致串口被尝试打开两次，资源冲突

**修复方案**:

1. **测试用例：移除多余的串口操作** (`test_cases/stability/multi_device_firmware_upgrade_stability_test.py` 第345-354行)
```python
# 修改前: 手动打开/关闭串口
if not serial_client.open():
    raise Exception("串口打开失败")
if not serial_client.flash_old_firmware(bridge_ip=bridge_ip):
    raise Exception("串口烧录失败")
serial_client.close()

# 修改后: 让 flash_old_firmware() 自己管理
if not serial_client.flash_old_firmware(bridge_ip=bridge_ip):
    raise Exception("串口烧录失败")
```

2. **串口客户端：自动检查并打开串口** (`utils/serial_client.py` 第667-672行)
```python
def flash_old_firmware(self, bridge_ip: str) -> bool:

    if not self.serial or not self.serial.is_open:
        print(f"串口未打开，正在打开 {self.port}...")
        if not self.open():
            return False

    # 2. 重启进Boot模式
```
