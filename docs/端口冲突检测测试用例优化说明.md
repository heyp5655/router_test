# 端口冲突检测测试用例优化说明

## 问题现象
运行测试用例时，页面一直在添加端口映射，无限循环。

## 根本原因

### 问题1: 测试端口数量过大 ❌
**原设计**: 遍历1-65535所有端口
**耗时**: 约18-36小时（假设每个端口1-2秒）
**实际**: 根本无法完成，不现实

### 问题2: 缺少清理机制 ❌
**表现**: 每次测试后不关闭表单
**结果**: 页面一直停留在添加表单状态
**导致**: 下一次循环又点击"添加"按钮，表单重复打开

### 问题3: 成功添加的规则未删除 ❌
**问题**: 非保留端口测试通过后，规则被实际添加到路由器
**结果**: 每测试一个非保留端口就添加一条规则
**影响**: 路由器规则表越来越多，影响性能

## 优化方案

### ✅ 优化1: 精简测试端口数量

**修改前**:
```python
# 遍历所有端口 1-65535
for test_port in range(1, 65535 + 1):
    # 测试每个端口
    ...
```

**修改后**:
```python
# 1. 测试所有保留端口（15个）
test_port_list = self.RESERVED_PORTS.copy()

# 2. 添加对照测试端口（10个）
non_reserved_samples = [80, 443, 8080, 3000, 5000, 9000, 10000, 20000, 30000, 50000]
test_port_list.extend([p for p in non_reserved_samples if p not in self.RESERVED_PORTS])

# 总共测试 25 个端口
for test_port in test_port_list:
    # 测试每个端口
    ...
```

**测试策略**:
- **保留端口** (15个): 验证都能触发冲突提示
- **非保留端口** (10个): 验证都不触发冲突提示
- **总耗时**: 约25-50秒（每个端口1-2秒）

### ✅ 优化2: 添加清理机制

**新增方法**: `_close_form()`
```python
def _close_form(self):
    """关闭端口映射添加/编辑表单"""
    try:
        # 查找并点击取消按钮
        cancel_button = WebDriverWait(driver, 2).until(
            EC.element_to_be_clickable((By.XPATH, '//button[contains(text(), "取消")]'))
        )
        cancel_button.click()
    except TimeoutException:
        # 表单已关闭，忽略
        pass
```

**调用时机**:
- 填写表单失败 → 关闭表单
- 保留端口测试完成 → 关闭表单
- 非保留端口冲突（异常） → 关闭表单
- 任何异常情况 → 关闭表单

### ✅ 优化3: 清理已添加的规则

**新增方法**: `_cleanup_added_rule()`
```python
def _cleanup_added_rule(self):
    """清理刚添加的端口映射规则"""
    # 刷新页面，清除未应用的更改
    self.router_client.driver.refresh()
    time.sleep(2)
```

**调用时机**:
- 非保留端口测试通过（无冲突）→ 刷新页面清理

```

  → ...
  → 无限循环65535次（永远完不成）
```

### 修改后 ✅
```
开始测试（只测试25个端口）
  → 点击添加按钮
  → 填写表单（端口22）
  → 点击保存
  → 检查弹窗（有弹窗）

  → 点击添加按钮
  → 填写表单（端口80）
  → 点击保存
  → 检查弹窗（无弹窗）
  → [刷新页面清理] ✅

  → ... 重复25次
  → 测试完成 ✅
```

| **预计耗时** | 18-36小时 | 25-50秒 | -99.97% |

## 测试覆盖说明

### 为什么不测试全部65535个端口？

1. **时间成本**: 18-36小时不现实
2. **实际需求**: 只需验证保留端口列表的**准确性**
3. **测试策略**:
   - 保留端口 (15个) → 验证都能检测出冲突 ✅
   - 非保留端口 (10个) → 验证都不误报 ✅
   - 结论: 保留端口列表准确 ✅

### 如何测试全部端口？

如有需要，可以修改测试代码：

```python
# 在 execute() 方法中
# 取消注释以下代码，注释掉当前的端口列表

# 测试全部端口 (需要18-36小时)
test_port_list = list(range(1, 65536))
```

⚠️ **警告**:
- 确保有足够时间（建议周末或夜间运行）
- 路由器会添加大量规则，测试前备份配置
- 测试完成后需要手动清理路由器规则表
