## 🔑 核心代码结构

### execute() 执行流程
```python
def execute(self):
    # 1. 配置MQTT客户端（智能复用已有配置）
    self.configure_mqtt_client()

    # 2. 发送MQTT请求（不等待响应）
    self.send_cellular_query_only()  # ← 关键：立即发送

    # 3. 立即获取页面数据（确保实时性）
    self.page_data = self.get_page_cellular_data()  # ← 关键：几乎同时

    # 4. 等待并接收MQTT响应
    self.receive_cellular_response()

    # 5. 验证数据一致性
    self.verify_data_consistency()
```

### 主要方法说明
- `configure_mqtt_client()` - 配置MQTT（含智能复用逻辑）
- `get_page_cellular_data()` - 获取页面数据（Summary + Detail）
- `send_cellular_query_only()` - 只发送MQTT请求
- `receive_cellular_response()` - 只接收MQTT响应
- `verify_data_consistency()` - 验证数据
  - `verify_modem_data()` - 验证modem字段
  - `verify_network_data()` - 验证network字段
  - `verify_statistics_data()` - 验证statistics字段
