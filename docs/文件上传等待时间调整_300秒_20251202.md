## 🔧 代码修改

### 修改文件
**文件**: `core/router_client.py`
**方法**: `upload_and_upgrade_firmware()`
**位置**: 第2656-2672行

### 修改前（120秒）
```python
# 6. 等待文件上传完成（约2分钟）
print(f"\n步骤6: 等待文件上传到路由器...")
print("  ⚠️ 文件上传需要约2分钟，请勿关闭浏览器！")
upload_wait_time = 120  # 等待2分钟让文件上传完成

# 每10秒输出一次进度
for i in range(0, upload_wait_time, 10):
    remaining = upload_wait_time - i
    print(f"  ⏳ 上传中... 还需等待约 {remaining} 秒")
    time.sleep(10)

print("  ✅ 文件上传完成，路由器开始处理...")
```

### 修改后（300秒）
```python
# 6. 等待文件上传完成（约5分钟）
print(f"\n步骤6: 等待文件上传到路由器...")
print("  ⚠️ 文件上传需要约5分钟，请勿关闭浏览器！")
upload_wait_time = 300  # 等待5分钟让文件上传完成

# 每10秒输出一次进度
for i in range(0, upload_wait_time, 10):
    remaining = upload_wait_time - i
    minutes = remaining // 60
    seconds = remaining % 60
    if minutes > 0:
        print(f"  ⏳ 上传中... 还需等待约 {minutes} 分 {seconds} 秒")
    else:
        print(f"  ⏳ 上传中... 还需等待约 {seconds} 秒")
    time.sleep(10)

print("  ✅ 文件上传完成，路由器开始处理...")
```

### 主要变更
1. ✅ `upload_wait_time`: 120 → 300（+180秒）
2. ✅ 提示信息: "约2分钟" → "约5分钟"
3. ✅ 进度显示: 优化为"分钟 + 秒"格式，更清晰

### 为什么需要300秒？

#### 可能的延迟因素
1. **固件文件大小**: 可能 > 50MB
2. **网络速度**:
   - 理想：千兆网络 ~1秒
   - 实际：可能受限于路由器处理速度
3. **路由器处理**:
   - 接收文件（慢）
   - 校验完整性
   - 临时存储准备
4. **浏览器行为**:
   - 分块上传
   - 进度更新延迟

#### 实际测试反馈
- 用户反馈：120秒不够用
- 保守估计：300秒确保完整上传
- 原则：宁可多等，不要失败
