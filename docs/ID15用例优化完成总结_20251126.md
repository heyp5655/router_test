## ⚠️ 注意事项

### 1. MQTT服务器配置
- 需要在 `config/default_config.yaml` 中配置MQTT服务器信息
- 包括：broker, port, username, password

### 2. 路由器蜂窝网络状态
- 测试前确保路由器已插入SIM卡
- 蜂窝网络必须已连接（Status不是Down）

### 3. SSH密码配置
- 当前SSH密码设置为 `"password"`
- 实际使用时需要根据路由器实际SSH密码修改
- 位置：`__init__()` 方法中的 `self.SSH_ROOT_PASSWORD`

### 4. 字段对比规则
- 所有字段大小写不敏感
- 会去除前后空格
- modem_status使用包含关系判断
- IPv4/IPv6会去除子网掩码/前缀长度
- DNS只对比第一个
