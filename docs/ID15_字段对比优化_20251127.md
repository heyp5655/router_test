# ID15 MQTT蜂窝状态上报 - 字段对比优化

**修改时间**: 2025-11-27
**修改内容**:
1. 移除RSRP、RSRQ、SINR字段的对比（信号值实时变化）
2. 增加SIM APN完整字段对比（IPv6 DNS + Connection Duration）

---

## 修改背景

### 问题描述
1. **RSRP、RSRQ、SINR值对比不稳定**
   - 这些信号值实时变化，即使页面锁定也可能在MQTT响应时已变化
   - 导致测试用例成功率不稳定
   - 这些字段不是核心功能验证点

2. **SIM APN字段对比不完整**
   - 原来只对比6个字段：Status, IPv4, IPv4 Gateway, IPv4 DNS, IPv6, IPv6 Gateway
   - 缺少2个字段：IPv6 DNS, Connection Duration
   - 无法全面验证APN数据的完整性

---

**修改后** (15个modem字段):
```python
field_mapping = {
    'modem_status': 'Summary Status',
    'model': 'Model',
    'version': 'Version',
    'cur_sim': 'Current SIM',
    'signal': 'Signal Level',
    'register': 'Register Status',

    # 已移除: 'rsrq': 'RSRQ',
    # 已移除: 'sinr': 'SINR',
}
```

**原因**:
- RSRP (Reference Signal Received Power) - 参考信号接收功率
- RSRQ (Reference Signal Received Quality) - 参考信号接收质量
- SINR (Signal to Interference plus Noise Ratio) - 信号与干扰加噪声比
- 这三个值都是实时信号指标，每秒都在变化
- 即使页面锁定，MQTT请求到响应的时间差（约1-2秒）内值可能已变化
- 这些不是核心功能验证点，移除后测试更稳定

### 2. 增加SIM APN完整字段对比

**文件**: `test_cases/mqtt_test/mqtt_cellular_status_report_test.py`
**方法**: `verify_network_data()` (约681-743行)

**修改前** (6个APN字段):
```python
field_mapping = {
    'status': 'Status',
    'ip': 'IPv4',
    'gate': 'IPv4 Gateway',
    'dns': 'IPv4 DNS',
    'ipv6': 'IPv6',
    'gatev6': 'IPv6 Gateway',

    # 缺少: 'time': 'Connection Duration'

```

**修改后** (8个APN字段):
```python
field_mapping = {
    'status': 'Status',
    'ip': 'IPv4',
    'gate': 'IPv4 Gateway',
    'dns': 'IPv4 DNS',
    'ipv6': 'IPv6',
    'gatev6': 'IPv6 Gateway',
    'dnsv6': 'IPv6 DNS',          # ← 新增
    'time': 'Connection Duration', # ← 新增
}
```

**新增字段说明**:

1. **IPv6 DNS** (`dnsv6`)
   - MQTT字段: `dnsv6`
   - 页面字段: `IPv6 DNS`
   - 页面XPath: `//*[@id="{apn_idx}_dnsv6"]`
   - 说明: IPv6的DNS服务器地址

2. **Connection Duration** (`time`)
   - MQTT字段: `time`
   - 页面字段: `Connection Duration`
   - 页面XPath: `//*[@id="{apn_idx}_time"]`
   - 说明: APN连接持续时长

**对比范围**:
- SIM1-APN1 的所有8个字段
- SIM1-APN2 的所有8个字段
- SIM1-APN3 的所有8个字段

## 数据处理规则

### IPv4地址处理
```python
# 页面格式: "10.3.218.11/28"
# MQTT格式: "10.3.218.11"
# 处理: 取'/'前的部分对比
if '/' in page_value:
    page_value = page_value.split('/')[0]
```

### IPv6地址处理
```python
# 页面格式: "fe80::1234:5678/64"
# MQTT格式: "fe80::1234:5678"
# 处理: 取'/'前的部分对比
if '/' in page_value:
    page_value = page_value.split('/')[0]
```

### DNS处理
```python
# 页面格式: "8.8.8.8, 8.8.4.4" (多个DNS)
# MQTT格式: "8.8.8.8" (单个DNS)
# 处理: 取第一个DNS对比
if ', ' in page_value:
    page_value = page_value.split(', ')[0]
```

### Connection Duration处理
```
# 页面格式: "1h 23m 45s" 或 "23m 45s" 或 "45s"
# MQTT格式: 通常相同格式
# 处理: 直接字符串对比（转小写）
```

## 优势与影响

### 优势
1. **提高测试稳定性**
   - 移除实时变化的信号值，避免误报
   - 测试成功率更高，结果更可靠

2. **增强数据完整性验证**
   - 新增IPv6 DNS和Connection Duration对比
   - 更全面地验证APN配置的正确性
   - 覆盖所有重要的网络配置字段

3. **更符合测试目标**
   - 专注于配置数据的一致性验证
   - 而非实时变化的信号质量监测

### 影响
1. **对现有测试的影响**
   - 不影响其他测试用例
   - 只修改ID15测试用例的验证逻辑

2. **对MQTT响应的要求**
   - MQTT响应需要包含`dnsv6`和`time`字段
   - 如果MQTT响应缺少这些字段，会显示不一致但不会失败
