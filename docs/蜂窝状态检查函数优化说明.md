# 蜂窝状态检查函数优化说明

## 概述

已将原有的 `check_cellular_status()` 函数拆分为两个独立的函数，同时保留了兼容性方法。

---

## 新增函数

### 1. `check_cellular_summary_status(timeout=30)`

检查 **#status/summary** 页面的蜂窝网络状态

#### 参数
- `timeout`: 超时时间(秒)，默认30秒

#### 返回值
返回一个字典，包含以下字段：

```python
{
    'success': bool,           # 是否获取成功
    'link_status': str,        # 链路状态/当前链路
    'status': str,             # 状态 (Ready, FDD LTE等)
    'current_network': str,    # 当前接入网络 (SIM1-APN1等)
    'ipv4': str,               # IPv4地址
    'ipv6': str,               # IPv6地址
    'connection_time': str,    # 连接时长
    'data_usage': str,         # SIM卡数据用量统计
    'error': str               # 错误信息(如果有)
}
```

#### 使用示例

```python
# 基本使用
result = router_client.check_cellular_summary_status()
if result['success']:
    print(f"状态: {result['status']}")
    print(f"当前网络: {result['current_network']}")
    print(f"IPv4: {result['ipv4']}")
    print(f"连接时长: {result['connection_time']}")
else:
    print(f"获取失败: {result['error']}")

# 自定义超时时间
result = router_client.check_cellular_summary_status(timeout=60)
```

#### 页面对应关系

| 字段名 | 页面显示名称 | XPath ID |
|--------|-------------|----------|
| link_status | 蜂窝状态/Link in use | qwert_modem |
| status | 状态 | qwert_status |
| current_network | 当前接入网络 | qwert_cur_sim |
| ipv4 | IPv4 | qwert_ip |
| ipv6 | IPv6 | qwert_ipv6 |
| connection_time | 连接时长 | qwert_time |
| data_usage | SIM卡数据用量统计 | qwert_total |

### 2. `check_cellular_detail_status(timeout=30)`

检查 **#status/cellular** 页面的详细蜂窝网络状态

#### 参数
- `timeout`: 超时时间(秒)，默认30秒

#### 返回值
返回一个字典，包含详细的状态信息：

```python
{
    'success': bool,                # 是否获取成功
    'error': str,                   # 错误信息(如果有)

    # 蜂窝运行状态
    'module_type': str,             # 模块型号
    'firmware': str,                # 版本
    'current_sim': str,             # 当前SIM卡
    'signal_strength': str,         # 信号强度
    'registration_status': str,     # 注册状态
    'imei': str,                    # IMEI
    'imsi': str,                    # IMSI
    'iccid': str,                   # ICCID
    'carrier': str,                 # 运营商
    'network_type': str,            # 网络类型
    'frequency_band': str,          # 频繁频段
    'plmn_id': str,                 # PLMN ID
    'location_code': str,           # 位置区码
    'cell_id': str,                 # Cell ID
    'rsrp': str,                    # RSRP
    'rsrq': str,                    # RSRQ
    'sinr': str,                    # SINR

    # 月度数据统计
    'monthly_stats': {
        'SIM-1': str,               # SIM-1流量: RX/TX/ALL
        'SIM-2': str                # SIM-2流量: RX/TX/ALL
    },

    # SIM卡APN信息
    'sim_apn_info': [
        {
            'name': str,            # APN名称 (SIM1-APN1等)
            'status': str,          # 状态 (Connected/Disconnected)
            'ipv4': str,            # IPv4地址
            'ipv4_gateway': str,    # IPv4网关
            'ipv4_dns': str,        # IPv4 DNS
            'ipv6': str,            # IPv6地址
            'ipv6_gateway': str,    # IPv6网关
            'ipv6_dns': str,        # IPv6 DNS
            'connection_time': str  # 连接时长
        },
        # ... 最多3个APN
    ]
}
```

#### 使用示例

```python
# 基本使用
result = router_client.check_cellular_detail_status()
if result['success']:
    print(f"模块型号: {result['module_type']}")
    print(f"网络类型: {result['network_type']}")
    print(f"信号强度: {result['signal_strength']}")
    print(f"IMEI: {result['imei']}")
    print(f"运营商: {result['carrier']}")

    # 打印APN信息
    for apn in result['sim_apn_info']:
        print(f"\n{apn['name']}:")
        print(f"  状态: {apn['status']}")
        print(f"  IPv4: {apn['ipv4']}")
        print(f"  连接时长: {apn['connection_time']}")
else:
    print(f"获取失败: {result['error']}")

# 访问月度统计
if 'SIM-1' in result['monthly_stats']:
    print(f"SIM-1月度流量: {result['monthly_stats']['SIM-1']}")
```

### 3. `check_cellular_status()` (兼容性方法)

保持向后兼容的方法，内部调用上述两个新函数。

#### 返回值
- `bool`: 所有检查条件都满足返回 True，否则返回 False

#### 使用示例

```python
# 现有代码无需修改，仍然可以正常工作
if router_client.check_cellular_status():
    print("蜂窝网络状态正常")
else:
    print("蜂窝网络状态异常")
```

#### 内部逻辑
1. 调用 `check_cellular_summary_status(timeout=30)`
2. 调用 `check_cellular_detail_status(timeout=30)`
3. 验证关键字段是否都有值
4. 只有当两个页面的关键信息都成功获取时才返回 `True`

## 关键特性

### 1. 超时机制
- 每个函数都支持自定义超时时间
- 在超时时间内循环检查，直到获取到所有必需字段的值
- 如果超时仍未获取到值，返回失败并说明原因

### 2. 详细的错误信息
- 当获取失败时，`error` 字段会包含详细的错误描述
- 帮助快速定位问题

### 3. 容错处理
- 使用 `try-except` 捕获每个字段的获取异常
- 即使部分字段获取失败，也不会影响其他字段
- 提供警告信息但继续执行

### 4. 实时反馈
- 打印详细的获取过程和结果
- 显示剩余等待时间
- 便于调试和监控

## 迁移指南

### 现有代码无需修改
如果你的代码已经在使用 `check_cellular_status()`，无需做任何修改，兼容性方法会继续工作。

```python
# 这段代码仍然有效
status = router_client.check_cellular_status()
if status:
    print("OK")
```

### 升级到新API（推荐）
如果你需要获取详细的状态信息，可以升级到新API：

**之前：**
```python
# 只能得到 True/False
status = router_client.check_cellular_status()
if status:
    print("连接成功")
```

**现在：**
```python
# 可以获取详细信息
result = router_client.check_cellular_summary_status()
if result['success']:
    print(f"连接成功 - IPv4: {result['ipv4']}, 时长: {result['connection_time']}")
else:
    print(f"连接失败: {result['error']}")
```

## 常见问题

### Q1: 为什么要拆分成两个函数？
**A**:
1. 提高代码可维护性和可读性
2. 允许独立获取不同页面的信息
3. 提供更灵活的API供不同场景使用

### Q2: 超时时间设置多少合适？
**A**:
- 默认30秒适用于大多数情况
- 如果网络较慢或模块启动需要更长时间，可以增加到60-120秒
- 建议根据实际测试情况调整

### Q3: 如果只需要部分信息怎么办？
**A**:
- 使用对应的函数获取整个结果字典
- 然后只使用你需要的字段
- 函数会获取所有字段，但你可以选择性使用

### Q4: 兼容性方法会被移除吗？
**A**:
- 不会，`check_cellular_status()` 会一直保留
- 但建议新代码使用新的API获取更详细的信息
