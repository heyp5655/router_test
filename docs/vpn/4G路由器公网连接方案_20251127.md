## ❌ 当前问题

### 路由器日志显示
```
racoon: initiate new phase 1 negotiation: 10.9.139.97[500]<=>112.48.19.183[500]
racoon: phase1 negotiation failed due to time up.
```

### 根本原因

**NAT端口映射配置错误**：

| 当前配置 | 问题 |
|---------|------|
| 112.48.19.183:11025 → 192.168.50.48:500 | ❌ 路由器发送到500端口，NAT监听11025，不匹配 |
| 112.48.19.183:11026 → 192.168.50.48:4500 | ❌ 路由器发送到4500端口，NAT监听11026，不匹配 |

**为什么会超时**：
1. 路由器按IPSec标准发送到 `112.48.19.183:500`
2. NAT网关在端口500上**没有监听**（只监听11025）
3. 数据包被NAT网关**丢弃**
4. 服务器永远收不到请求
5. 路由器等待50秒后超时

---

## ✅ 解决方案：修改NAT端口映射

### 步骤1：删除旧的端口映射

在NAT网关上删除：
```
112.48.19.183:11025 → 192.168.50.48:500   ❌ 删除
112.48.19.183:11026 → 192.168.50.48:4500  ❌ 删除
112.48.19.183:11027 → 192.168.50.48:50    ❌ 删除
112.48.19.183:11028 → 192.168.50.48:47    ❌ 删除
```

### 步骤2：添加标准端口映射

在NAT网关上添加：
```
外部接口：112.48.19.183
协议：UDP

端口映射规则：
外部端口 500  → 内部IP 192.168.50.48:500   ✅ 新增 (IKE协商)
外部端口 4500 → 内部IP 192.168.50.48:4500  ✅ 新增 (NAT-T数据传输)
```

### 步骤3：保存并应用NAT配置

## 🔍 为什么必须用标准端口？

### IPSec协议标准 (RFC)

- **RFC 2408**: IKE协议使用 UDP 500
- **RFC 3947**: NAT-T使用 UDP 4500
- 这是**国际标准**，所有IPSec设备都遵守

### Racoon的限制

```c
// Racoon源码硬编码
#define PORT_ISAKMP 500
#define PORT_ISAKMP_NATT 4500

// 配置文件中无法修改监听端口
// 只能监听标准端口
```

### 路由器的行为

```
路由器配置Hub为: 112.48.19.183
路由器自动发送到: 112.48.19.183:500

无法配置路由器连接到:11025等非标准端口
```

## 🐛 故障排查

### 问题1：修改NAT后仍超时

**检查**：
```bash
# 在NAT网关上抓包
tcpdump -i <外部接口> -n port 500 or port 4500

# 应该能看到来自10.9.139.97的数据包
```

**可能原因**：
- NAT配置未生效，需要重启NAT服务
- 防火墙阻止UDP 500/4500
- 外部接口配置错误

### 问题2：服务器收不到数据包

**检查**：
```bash
# 在服务器上抓包
sudo tcpdump -i any -n port 500 or port 4500

# 应该能看到来自NAT内网接口的数据包
```

**可能原因**：
- NAT转发规则配置错误
- 内网路由问题

### 问题3：Phase1仍然失败

**查看详细日志**：
```bash
# 服务器端
sudo tail -100 /var/log/syslog | grep racoon

# 路由器端
tail -100 /etc/urlog/vpn.log
```

**常见错误**：
- `no proposal chosen` → 加密参数不匹配
- `authentication failed` → PSK密钥不匹配
- `time up` → 网络不通或端口映射错误
