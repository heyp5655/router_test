#### ✅ 服务器端配置更新
**问题**: 服务器配置只允许特定IP列表的路由器连接，不支持4G路由器动态IP

**解决**: 修改为 `remote anonymous` 模式

**配置变更**:
```diff
- remote 192.168.50.16 { ... }     # 只允许特定IP
- remote 192.168.40.207 { ... }
- remote 10.33.126.188 { ... }
- remote 10.117.203.7 { ... }

+ remote anonymous {                # 允许任意IP（只要PSK正确）
+     exchange_mode main;
+     my_identifier address;
+     peers_identifier address;
+     nat_traversal on;
+     proposal {
+         encryption_algorithm aes 128;
+         hash_algorithm sha1;
+         authentication_method pre_shared_key;
+         dh_group modp3072;
+         lifetime time 10800 sec;
+     }
+     dpd_delay 30;
+     dpd_retry 5;
+     dpd_maxfail 5;
+ }
```

## ⚠️ 关键配置项检查

### 1. 路由器Hub地址配置

**4G路由器必须配置为公网IP**，因为服务器在NAT后面：

```
Hub地址: 112.48.19.183  ← 必须是这个公网IP！
```

**❌ 错误配置**:
```
Hub地址: 192.168.50.48   ← 这是内网IP，4G路由器无法访问！
```

### 2. NAT端口映射检查

上级路由器(112.48.19.183)必须配置端口映射：

```
外网端口 → 内网服务器
500  (UDP) → 192.168.50.48:500
4500 (UDP) → 192.168.50.48:4500
```

**验证方法**:
```bash
# 从外网测试UDP 500端口是否开放
nc -u -v 112.48.19.183 500

# 或使用nmap
nmap -sU -p 500,4500 112.48.19.183
```

### 3. 4G路由器DMVPN配置

**必须配置的参数**:

```yaml
基本配置:
  - 启用: ✓ (勾选)
  - Hub地址: 112.48.19.183  ← 公网IP！
  - PSK密钥: 123456

Phase 1 (IKE):
  - 模式: Main Mode
  - 加密: AES-128
  - 认证: SHA1
  - DH组: MODP3072 (Group 15)
  - 生存时间: 10800秒
  - NAT穿透: 启用

Phase 2 (IPSec SA):
  - 加密: AES-128
  - 认证: HMAC-SHA1
  - 生存时间: 3600秒

GRE配置:
  - GRE Hub IP: 10.0.0.1
  - GRE本地IP: 10.0.0.x (例如 10.0.0.10)
  - GRE子网掩码: 255.255.255.0
  - GRE密钥: 123456
```

## 诊断步骤

### 步骤1: 确认路由器Hub地址
在4G路由器Web界面检查:
```
DMVPN配置 → Hub地址 = ？
```

- ✅ 如果是 `112.48.19.183` → 正确，继续下一步
- ❌ 如果是 `192.168.50.48` → **错误**，需要改为公网IP

### 步骤2: 测试NAT端口映射
从4G路由器或手机(使用4G网络)测试:
```bash
# 测试UDP 500端口
ping 112.48.19.183

# 如果有公网服务器，从公网测试
telnet 112.48.19.183 500
```

### 步骤3: 查看服务器日志
```bash
python scripts/vpn_tools/monitor_connection_attempt.py
```

在4G路由器上**重新启用DMVPN**，观察服务器日志：

**成功标志**:
```
INFO: respond new phase 1 negotiation: 192.168.50.48[500]<=>10.193.64.158[xxx]
INFO: ISAKMP-SA established
INFO: IPsec-SA established
```

**失败标志**:
```
ERROR: no suitable proposal found        ← 加密参数不匹配
ERROR: timeout                           ← 网络不通或端口未映射
ERROR: authentication failed             ← PSK密钥错误
```

### 步骤4: 检查防火墙
服务器防火墙必须允许UDP 500和4500：
```bash
sudo iptables -A INPUT -p udp --dport 500 -j ACCEPT
sudo iptables -A INPUT -p udp --dport 4500 -j ACCEPT
```

## 常见问题排查

### Q1: 路由器显示"未连接"
**可能原因**:
1. Hub地址配置错误（使用了内网IP 192.168.50.48）
2. NAT端口映射未配置
3. PSK密钥不匹配
4. 加密参数不匹配

**排查**:
```bash
# 服务器端监控日志
python -c "
import paramiko
ssh = paramiko.SSHClient()
ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
ssh.connect('192.168.50.48', username='yuxy', password='milesight123')
stdin, stdout, stderr = ssh.exec_command('sudo tail -f /var/log/syslog | grep racoon')
print(stdout.read().decode('utf-8', errors='ignore'))
ssh.close()
"
```

### Q2: 服务器日志无任何连接尝试
**原因**: NAT端口映射未配置或路由器Hub地址错误

**解决**:
1. 确认路由器Hub地址为 `112.48.19.183`
2. 确认NAT路由器已映射 500 和 4500 端口

### Q3: 日志显示"no suitable proposal found"
**原因**: 加密参数不匹配

**解决**: 确认路由器配置为:
- AES-128 + SHA1 + MODP3072
