## 🔍 故障排查

### 如果路由器无法连接到192.168.50.48

**可能原因**:
1. 路由器和服务器不在同一网络
2. 防火墙阻止UDP 500/4500
3. 路由问题

**解决方案**:

#### 方案A: 使用公网IP (如果路由器在外网)
```
Hub地址: 112.48.19.183
Hub端口: 500
```

**但需要确认NAT端口映射**:
- 112.48.19.183:500 → 192.168.50.48:500
- 112.48.19.183:4500 → 192.168.50.48:4500

#### 方案B: 测试连通性
在路由器上执行:
```bash
ping 192.168.50.48
```

如果ping不通，则必须使用公网IP 112.48.19.183
