# DMVPN连接失败修复指南

## 问题诊断

**错误**: `ERROR: no suitable proposal found` - Phase 1协商失败

**原因**: 服务器配置的加密参数与路由器发送的proposal不匹配

**当前服务器配置** (由GUI工具生成):
- Phase 1: AES-256 + SHA256 + MODP3072 (DH Group 15)
- Phase 2: AES-256 + HMAC-SHA256

**路由器需要的配置** (更常用/兼容性更好):
- Phase 1: AES-128 + SHA1 + MODP1024 (DH Group 2)
- Phase 2: AES-128 + HMAC-SHA1

---

## 修复方案 (选择其中一种)

### 方案A: 使用一键修复脚本 ⭐推荐

运行以下命令自动降级服务器配置:

```bash
python scripts/vpn_tools/fix_dmvpn_compatibility.py
```

脚本会自动:
1. 备份当前配置
2. 修改为路由器兼容参数 (AES-128 + SHA1 + DH Group 2)
3. 重启Racoon服务
4. 验证配置是否生效

---

### 方案B: 使用GUI工具重新配置

**步骤1**: 启动DMVPN配置工具

```bash
# 双击运行
启动DMVPN配置工具.bat

# 或命令行启动
python scripts/vpn_tools/dmvpn_config_gui.py
```

**步骤2**: 修改加密参数

在GUI界面中修改以下参数:

**IPSec Phase 1配置** 区域:
- 加密算法: `AES128` (从 AES256 改为 AES128)
- 认证算法: `SHA1` (从 SHA2-256 改为 SHA1)
- DH组: `MODP1024-2` (从 MODP3072-15 改为 MODP1024-2)

**IPSec Phase 2配置** 区域:
- SA算法: `AES128-SHA1` (从 AES256-SHA2-256 改为 AES128-SHA1)

**步骤3**: 点击"应用配置到服务器"按钮

等待配置应用完成，查看日志确认服务重启成功。

---

### 方案C: 修改路由器配置匹配服务器

如果路由器支持高级加密参数，可以在路由器Web界面配置:

**DMVPN配置页面**:
- Phase 1加密: AES-256
- Phase 1认证: SHA256 (或 SHA2-256)
- DH组: Group 15 (MODP3072)
- Phase 2加密: AES-256
- Phase 2认证: HMAC-SHA256

**注意**: 多数路由器默认不支持这些高级参数，推荐使用方案A或B降级服务器配置。

## 常见问题

### Q1: 修复后仍然连接失败?

**检查路由器配置是否完全匹配服务器**:
- 运行 `python scripts/vpn_tools/monitor_connection_attempt.py`
- 在路由器端重新启用DMVPN
- 观察日志中的错误信息

常见错误:
- `authentication failed` → PSK密钥不匹配 (应该是 `123456`)
- `no proposal chosen` → 加密参数仍然不匹配
- `timeout` → 网络连通性问题或Hub地址错误

### Q2: 服务器能接收连接但GRE不通?

检查GRE配置:
```bash
python -c "
import paramiko
ssh = paramiko.SSHClient()
ssh.set_missing_host_key_policy(paramiko.AutoAddPolicy())
ssh.connect('192.168.50.48', username='yuxy', password='milesight123')
stdin, stdout, stderr = ssh.exec_command('ip addr show gre1')
print(stdout.read().decode())
stdin, stdout, stderr = ssh.exec_command('ip tunnel show gre1')
print(stdout.read().decode())
ssh.close()
"
```

### Q3: GUI工具无法启动?

使用调试版启动脚本:
```bash
启动DMVPN配置工具_调试版.bat
```

查看详细错误信息，确认 `paramiko` 模块已安装:
```bash
pip install paramiko
```
