### 方法2: 手动SSH修复

#### 步骤1: SSH登录服务器

```bash
ssh yuxy@192.168.50.48

```

#### 步骤2: 检查GRE隧道（最常见问题）

```bash
# 查看GRE隧道

```

**如果没有gre1接口或显示"does not exist"**，执行以下命令重新创建：

```bash

sudo ip tunnel del gre1

sudo ip addr add 10.0.0.1/24 dev gre1
sudo ip link set gre1 up

# 验证
ip addr show gre1
```

**预期输出**:
```

    link/gre 192.168.50.48 brd 0.0.0.0
    inet 10.0.0.1/24 scope global gre1
```

#### 步骤3: 检查Racoon服务

```bash
# 查看服务状态
sudo systemctl status racoon
```

**如果不是"active (running)"**，重启服务：

```bash
sudo systemctl restart racoon
```

#### 步骤4: 测试连通性

```bash
# 从服务器ping路由器
ping -c 4 10.0.0.3
```

**预期**: 应该能ping通

#### 步骤5: 检查IPSec SA

```bash
# 查看安全关联
sudo setkey -D
```

**预期**: 应该看到192.168.50.48和192.168.50.16之间的SA

## 🔍 问题诊断清单

### 检查1: GRE隧道是否存在？

```bash
ip addr show gre1
```

- ✅ 显示 `inet 10.0.0.1/24` → GRE隧道正常
- ❌ 显示 `does not exist` → **需要重新创建GRE隧道**

### 检查2: Racoon服务是否运行？

```bash
sudo systemctl status racoon
```

- ✅ 显示 `active (running)` → 服务正常
- ❌ 显示 `inactive (dead)` → **需要启动服务**

### 检查3: 能否ping通路由器？

```bash
ping -c 4 10.0.0.3
```

- ✅ `4 received, 0% packet loss` → 连接正常
- ❌ `0 received, 100% packet loss` → **检查路由器配置**

### 检查4: IPSec SA是否建立？

```bash
sudo setkey -D | grep 192.168.50
```

- ✅ 显示 SA 信息 → IPSec正常
- ❌ 无输出 → **检查路由器PSK和加密参数**

## 🛠️ 常见问题及解决方案

### 问题1: GRE隧道重启后消失

**原因**: 永久化配置文件可能有问题

**解决方案A - 使用自动化脚本（推荐）**:

```bash
# 1. 确保脚本存在
ls ~/setup_gre_tunnel.sh

# 2. 运行脚本
sudo bash ~/setup_gre_tunnel.sh
```

**解决方案B - 检查永久化配置**:

```bash
# 查看配置文件
cat /etc/network/interfaces.d/gre1

# 应该包含:
auto gre1
iface gre1 inet static
    address 10.0.0.1
    netmask 255.255.255.0
    pre-up ip tunnel add gre1 mode gre local 192.168.50.48 key 123456
    post-down ip tunnel del gre1
```

**如果配置文件不存在或不正确**，创建它：

```bash
sudo nano /etc/network/interfaces.d/gre1

# 粘贴以下内容:
auto gre1
iface gre1 inet static
    address 10.0.0.1
    netmask 255.255.255.0
    pre-up ip tunnel add gre1 mode gre local 192.168.50.48 key 123456
    post-down ip tunnel del gre1

# 保存: Ctrl+O, Enter, Ctrl+X

# 启动隧道
sudo ifup gre1
```

### 问题2: Racoon服务未自动启动

**检查是否设置开机启动**:

```bash
sudo systemctl is-enabled racoon
```

**如果显示"disabled"**，启用开机启动：

```bash
sudo systemctl enable racoon
sudo systemctl start racoon
```

### 问题3: 能ping通10.0.0.1但不能ping通10.0.0.3

**原因**: 路由器端问题

**需要检查路由器**:
1. DMVPN是否启用
2. 加密参数是否匹配（AES-128, SHA1, 3DES-SHA1）
3. PSK密钥是否为 `123456`
4. GRE配置是否正确（GRE密钥 123456）

**在路由器Web界面执行**:
```
ping 10.0.0.1
```

### 问题4: IPSec SA不存在

**查看Racoon日志**:

```bash
sudo tail -100 /var/log/syslog | grep racoon
```

**常见错误**:

- `authentication failed` → PSK密钥不匹配，检查路由器PSK
- `no proposal chosen` → 加密算法不匹配，检查路由器加密参数
- `phase1 negotiation failed` → Phase 1参数不匹配

**解决**: 确认路由器配置匹配服务器要求:
- Phase 1: AES-128 + SHA1 + DH Group 1
- Phase 2: 3DES + HMAC-SHA1
- PSK: 123456
