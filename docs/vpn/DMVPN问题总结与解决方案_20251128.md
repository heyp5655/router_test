# DMVPN连接失败 - 问题总结与解决方案

## 问题现状

### 错误现象
路由器192.168.50.16持续尝试连接DMVPN服务器，但每次都失败：

```
ERROR: no suitable proposal found.
ERROR: failed to get valid proposal.
ERROR: phase1 negotiation failed.
```

### 根本原因
**服务器端和路由器端的IPSec加密参数不匹配！**

**当前服务器配置** (由GUI工具在12:21生成):
- Phase 1: **AES-256** + **SHA256** + **MODP3072** (DH Group 15)
- Phase 2: AES-256 + HMAC-SHA256

**路由器发送的Proposal** (从服务器日志推断):
- 可能是: AES-128 + SHA1 + MODP1024 (DH Group 2)
- 或其他较低级别的加密组合

**结论**: 路由器不支持或未配置AES-256+SHA256+MODP3072这样的高级加密参数。

---

## 解决方案

### 方案A: 修改路由器配置 (推荐)

**适用条件**: 路由器支持高级加密参数

**步骤**:
1. 登录路由器Web界面
2. 进入DMVPN配置页面
3. 修改IPSec参数匹配服务器:

```
Phase 1 (IKE):
  - 模式: Main Mode
  - 加密算法: AES-256
  - 认证算法: SHA-256 (或SHA2-256)
  - DH组: Group 15 (或MODP3072)
  - 生存时间: 10800秒

Phase 2 (IPSec SA):
  - 加密算法: AES-256
  - 认证算法: HMAC-SHA256
  - 生存时间: 3600秒

基本配置:
  - Hub地址: 192.168.50.48
  - PSK密钥: 123456
  - GRE密钥: 123456
  - GRE Hub IP: 10.0.0.1
  - GRE本地IP: 10.0.0.3 (或其他10.0.0.x)
```

4. 保存并应用配置
5. 启用DMVPN

### 方案B: 直接SSH修改服务器配置 (最直接有效)

```bash
# 1. SSH登录服务器
ssh yuxy@192.168.50.48
# 密码: milesight123

# 2. 备份配置
sudo cp /etc/racoon/racoon.conf /etc/racoon/racoon.conf.backup

# 3. 编辑配置文件
sudo nano /etc/racoon/racoon.conf

# 4. 找到所有 proposal 块，修改为:
#     encryption_algorithm aes 128;      # 从 aes 256 改为 128
#     hash_algorithm sha1;               # 从 sha256 改为 sha1
#     dh_group 2;                        # 从 modp3072 改为 2

# 5. 找到 sainfo anonymous 部分，修改为:
#     encryption_algorithm aes 128;      # 从 aes 256 改为 128
#     authentication_algorithm hmac_sha1; # 从 hmac_sha256 改为 hmac_sha1

# 6. 保存: Ctrl+O, Enter, Ctrl+X

# 7. 重启服务
sudo systemctl restart racoon

# 8. 验证配置
cat /etc/racoon/racoon.conf | grep -E "encryption|hash|dh_group" | head -6
sudo systemctl status racoon
```
