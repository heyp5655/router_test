# ID21测试用例快速使用指南

## 🎯 测试说明

**测试模式**: 串口烧录旧版本 → Web升级新版本

**测试流程**:
1. 串口烧录旧版本固件32.3.0.7（通过Boot模式 + TFTP）
2. Web登录路由器
3. 检查版本号是否为32.3.0.7
4. Web上传新版本固件32.3.0.9
5. 验证升级后版本号
6. 循环1000次

**并行测试**: 两台设备同时进行，效率提升50%

## 🔧 常见问题

### Q1: 串口打开失败

```
错误: 串口COM7打开失败
解决:
  1. 检查设备是否连接
  2. 关闭其他串口工具（PuTTY等）
  3. 检查COM口号是否正确（设备管理器）
```

### Q2: TFTP超时

```
错误: TFTP上传超时
解决:
  1. 检查TFTP服务器是否运行
  2. 检查网络连通性: ping 172.168.0.100
  3. 检查防火墙是否阻止UDP 69端口
  4. 检查固件文件名是否为: 32.3.0.7.ext2
```

### Q3: Web登录失败

```
错误: Web登录失败
解决:
  1. 检查PC能否访问: http://192.168.50.17
  2. 检查密码是否正确（默认: admin/password）
  3. 等待路由器完全启动（至少30秒）
```

### Q4: 版本号不匹配

```
错误: 版本号验证失败
解决:
  1. 检查固件文件版本是否正确
  2. 检查XPath是否正确: //*[@id="qwert_firmware_ver"]
  3. 查看实际版本号格式（可能有前缀）
```
