# 智能密码切换与修改密码弹窗处理优化

**日期**: 2025-12-10
**版本**: v1.0
**影响**: ID21 多设备固件升级稳定性测试

---

## 📋 优化概述

### 需求背景
用户反馈：烧录/升级后登录失败，需要更换密码。发现问题：
1. 烧录后设备密码可能恢复为默认密码 `password`
2. 首次登录时会弹出"修改密码"对话框
3. 如果不处理修改密码弹窗，后续操作会失败

### 优化目标
1. ✅ **智能密码切换**：自动尝试多个密码（password → admin1）
2. ✅ **强制处理弹窗**：每次登录成功后必须检查并处理修改密码弹窗
3. ✅ **密码自动更新**：弹窗处理后自动更新 `web_client.password`

## 🔧 修改内容

### 1. RouterClient - 修复 `login_web_force()` 方法

**文件**: `core/router_client.py`
**位置**: 第230-236行
**问题**: `login_web_force()` 方法登录成功后没有调用 `_handle_change_password_popup()`

**修改前**:
```python
# 验证登录成功的多种方法
if self._verify_login_success():
    print("强制登录验证成功")
    return True  # ❌ 直接返回，未处理修改密码弹窗
```

**修改后**:
```python
# 验证登录成功的多种方法
if self._verify_login_success():
    print("强制登录验证成功")

    # ⚠️ 关键：检查并处理修改密码弹窗
    self._handle_change_password_popup()

    return True  # ✅ 处理弹窗后再返回
```

**效果**:
- `login_web_force()` 现在与 `login_web()` 行为一致
- 确保每次强制登录后都处理修改密码弹窗

### 2. 测试用例 - 增强 `_login_web_with_fallback()` 方法

**文件**: `test_cases/stability/multi_device_firmware_upgrade_stability_test.py`
**位置**: 第785-864行
**问题**: 智能密码切换后，没有处理修改密码弹窗

**修改前**:
```python
# 尝试登录
if web_client.login_web_force():
    log_func(f"  ✅ 登录成功！使用密码: {'*' * len(password)}")
    log_func(f"     密码已自动切换为: {password}")
    return True  # ❌ 直接返回，未处理修改密码弹窗
```

**修改后**:
```python
# 尝试登录
if web_client.login_web_force():
    log_func(f"  ✅ 登录成功！使用密码: {'*' * len(password)}")

    # ⚠️ 关键步骤：检查并处理修改密码弹窗
    log_func(f"  🔍 检查是否有修改密码弹窗...")
    popup_handled = web_client._handle_change_password_popup()

    if popup_handled:
        log_func(f"  ✅ 已处理修改密码弹窗，密码已自动改为: admin1")
        log_func(f"     最终密码: {web_client.password}")
    else:
        log_func(f"  ℹ️  无修改密码弹窗")
        log_func(f"     最终密码: {web_client.password}")

    return True  # ✅ 处理弹窗后再返回
```

**效果**:
- 每次成功登录后，自动检查并处理修改密码弹窗
- 详细的日志输出，清晰显示处理过程
- 自动更新 `web_client.password` 为最终的密码

2. 如果密码1失败，尝试密码2: 'admin1'
   └─ （重复上述流程）

## 🔍 关键技术细节

### 1. `_handle_change_password_popup()` 方法行为

**返回值**:
- `True`: 检测到修改密码弹窗，并成功处理
- `False`: 未检测到修改密码弹窗（正常情况）

**副作用**:
- 如果处理成功，会自动更新 `web_client.password = 'admin1'`
- 会自动使用新密码重新登录

**调用时机**:
- `login_web()` - 第140行
- `login_web_force()` - 第235行 ⭐ 新增
- `_login_web_with_fallback()` - 第840行 ⭐ 新增

web_client._handle_change_password_popup()  # 返回 False（无弹窗）

### 基本用法（测试用例中）

## 📝 注意事项

### 1. 密码固定为 'admin1'
- `_handle_change_password_popup()` 会将密码固定改为 `admin1`
- 这是硬编码的，目前不支持自定义新密码
- 如需修改，需要调整 `_handle_change_password_popup()` 方法

### 2. 弹窗处理时间
- 检测弹窗：2秒
- 填写表单：1.5秒
- 等待跳转：5秒
- 重新登录：8秒
- **总计约16-18秒**

### 3. 日志输出
- 日志中密码显示为 `***`（隐藏敏感信息）
- 但实际密码明文会输出（便于调试）
- 生产环境建议移除明文密码输出
