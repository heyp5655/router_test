# ID41 URL路径修复 - 2025-12-15

## 🐛 问题描述

**问题现象**: 即使添加了页面刷新，升级页面仍然显示空白

**错误原因**: 升级页面的URL路径不正确

**错误URL**: `https://192.168.1.1/#system/upgrade`
**正确URL**: `https://192.168.1.1/#maintenance/upgrade/upgrade`

### 路由器Web界面路径规范

路由器的Hash路由结构：

```
根路径规范:
├── #status/         - 状态页面
│   └── summary      - 首页概览
├── #network/        - 网络配置
├── #system/         - 系统设置（⚠️ 不包含upgrade）
└── #maintenance/    - 维护管理
    └── upgrade/     - 升级管理
        └── upgrade  - 固件升级页面 ✅
```

**关键区别**:
- `#system/upgrade` - 不存在此路径 ❌
- `#maintenance/upgrade/upgrade` - 固件升级的正确路径 ✅

## 🎓 经验教训

### 1. URL路径的重要性

**问题**:
- 路由器使用Hash路由（SPA架构）
- URL路径必须精确匹配
- 错误的路径会导致404或空白页面

**教训**:
- ✅ 参考已有的成功实现（RouterClient）
- ✅ 手动验证URL的正确性
- ✅ 查看浏览器开发者工具

### 2. 调试步骤

遇到页面空白问题时的排查顺序：

1. **检查URL路径**（本次问题）⭐
   - 是否使用正确的Hash路由
   - 参考其他成功的实现

2. **检查刷新操作**（上次问题）
   - 是否有 `driver.refresh()`
   - 等待时间是否足够

3. **检查元素定位**
   - 选择器是否正确
   - 是否需要等待元素可见

4. **检查浏览器状态**
   - 是否已登录
   - 是否有弹窗遮挡

### 3. Hash路由规范

路由器Web界面的路径规范：

| 功能 | 正确路径 | 错误示例 |
|-----|---------|---------|
| 首页 | `#status/summary` | `#home`, `#index` |
| 固件升级 | `#maintenance/upgrade/upgrade` | `#system/upgrade` ❌ |
| 网络配置 | `#network/cellular/sim1` | `#cellular/sim1` |
| 系统设置 | `#system/general` | `#settings/general` |

**规律**:
- 第一级: 功能模块（status, network, system, maintenance）
- 第二级: 子功能（upgrade, cellular, general）
- 第三级: 具体页面（upgrade, sim1）
