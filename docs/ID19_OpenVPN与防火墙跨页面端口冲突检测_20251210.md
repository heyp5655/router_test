# ID19 - OpenVPN与防火墙跨页面端口冲突检测

## 📋 用例信息
- **测试ID**: ID19
- **测试名称**: OpenVPN与防火墙跨页面端口冲突检测
- **测试分类**: 功能用例/端口冲突检测
- **实现日期**: 2025-12-10

## 🎯 测试目标
测试OpenVPN服务器与防火墙FTP端口之间的跨页面端口冲突检测功能，验证路由器能够检测到不同配置页面之间的端口冲突。

## 📝 测试流程

### 阶段1：配置防火墙FTP端口
1. 跳转到防火墙Security页面 (`#network/firewall/security`)
2. 配置FTP端口为1111
3. 启用FTP功能（勾选FTP Enable复选框）
4. 保存并应用配置

### 阶段2：测试OpenVPN端口冲突
5. 跳转到OpenVPN服务器页面 (`#network/vpn/server`)
6. 启用OpenVPN服务器
7. 配置OpenVPN端口为1111（与FTP端口相同）
8. 验证是否弹出端口冲突提醒

## ✅ 预期结果
- **有弹窗** = ✅ 测试通过（跨页面端口冲突检测生效）
- **无弹窗** = ❌ 测试失败（跨页面端口冲突检测失效）

## 📁 实现文件

### 1. 测试用例文件
**路径**: `test_cases/port_conflict_tests/openvpn_firewall_cross_page_port_conflict_test.py`

**关键类**: `OpenVPNFirewallCrossPagePortConflictTest`
- 继承自 `BaseTest`
- 测试端口: 1111（可配置）
- 实现了完整的测试流程

### 2. RouterClient新增方法
**路径**: `core/router_client.py`

**新增方法**: `test_cross_page_port_conflict_openvpn_firewall(test_port: int = 1111) -> dict`

**方法功能**:
- 自动执行两阶段测试流程
- 配置防火墙FTP端口并启用
- 尝试在OpenVPN页面配置相同端口
- 检测是否弹出端口冲突提醒
- 返回详细的测试结果

**返回值结构**:
```python
{
    "success": bool,          # 是否检测到端口冲突弹窗
    "firewall_config": bool,  # 防火墙FTP配置是否成功
    "openvpn_conflict": bool, # OpenVPN是否检测到冲突
    "message": str            # 详细信息
}
```

## 🎓 测试意义
ID19测试用例验证了路由器的全局端口管理能力：
1. 确保不同功能页面之间能够共享端口占用信息
2. 防止用户在不同页面配置相同端口导致冲突
3. 提供友好的冲突提示，帮助用户快速定位问题

## ✨ 特色功能
1. **两阶段测试**: 分别验证防火墙配置和OpenVPN冲突检测
2. **详细日志**: 每个步骤都有清晰的日志输出
3. **错误处理**: 完善的异常处理机制
4. **可配置端口**: 默认1111，可修改为其他端口
5. **自动清理**: 测试完成后自动清理状态

## 📋 使用说明

1. 启动Flask应用: `python app.py` 或 `start_admin.bat`
2. 访问 http://localhost:5000
3. 在测试列表中找到 "OpenVPN与防火墙跨页面端口冲突检测"
