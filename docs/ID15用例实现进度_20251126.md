### 2. ID15 MQTT蜂窝状态上报测试用例 ✅

**文件位置**: `test_cases/mqtt_test/mqtt_cellular_status_report_test.py`

**用例信息**:
- **测试项**: 工业协议/网络/MQTT
- **测试点**: MQTT页面配置"蜂窝网络"上报功能-驻留网络
- **分类**: `category = "功能用例/服务/MQTT"`
- **回归测试**: `is_regression = True`

**已实现的功能**:

1. ✅ **MQTT配置流程** (`configure_mqtt_client()`)
   - 导航到 `#industrial/mqtt/status` 页面
   - 点击添加按钮
   - 启用MQTT客户端
   - 填写配置信息（名称、服务器、认证）
   - 配置主题（request/response）
   - 保存并应用配置
   - 等待MQTT连接建立（最长300秒）

2. ✅ **获取页面数据** (`get_page_cellular_data()`)
   - 调用 `router_client.check_cellular_detail_status()`
   - 返回完整的页面蜂窝状态数据

3. ✅ **发送MQTT查询** (`send_cellular_query()`)
   - 创建MQTT测试客户端
   - 连接到MQTT服务器
   - 订阅response主题
   - 发送命令: `{"id":"1","status":"cellular"}`
   - 接收并解析JSON响应

4. ✅ **数据验证** (`verify_data_consistency()`)
   - 验证响应基本格式（code, id, status, data字段）
   - 验证modem数据（17个字段对比）
   - 验证network数据（3个VPN/APN对比）
   - 验证statistics数据（SIM1/SIM2月度统计）

**数据对比逻辑**:

```python
# Modem字段映射（MQTT → 页面）
'model' → 'Model'
'version' → 'Version'
'cur_sim' → 'Current SIM'
'signal' → 'Signal Level'
'register' → 'Register Status'
'imei' → 'IMEI'
'imsi' → 'IMSI'
'iccid' → 'ICCID'
'net_provider' → 'ISP'
'net_type' → 'Network Type'
'band' → 'Cellular Frequency Band'
'plmnid' → 'PLMN ID'
'lac' → 'LAC'
'cellid' → 'Cell ID'
'rsrp' → 'RSRP'
'rsrq' → 'RSRQ'
'sinr' → 'SINR'

# Network字段映射（MQTT → 页面）
vpn1 → SIM APN Profile[0]
vpn2 → SIM APN Profile[1]
vpn3 → SIM APN Profile[2]

每个VPN的字段:
'status' → 'Status'
'ip' → 'IPv4' (去除/后的子网掩码)
'gate' → 'IPv4 Gateway'
'dns' → 'IPv4 DNS' (取第一个DNS)
'ipv6' → 'IPv6' (去除/后的前缀长度)
'gatev6' → 'IPv6 Gateway'

# Statistics字段映射
'sim1' → 'SIM-1 Monthly'
'sim2' → 'SIM-2 Monthly'
```

**特殊处理**:
- ✅ IP地址格式处理（页面: `10.3.218.11/28` → MQTT: `10.3.218.11`）
- ✅ IPv6格式处理（页面: `fe80::xxx/64` → MQTT: `fe80::xxx`）
- ✅ DNS格式处理（页面: `218.85.152.99, 218.85.157.99` → 取第一个）
- ✅ 空格标准化处理
- ✅ 大小写不敏感对比
- ⚠️  **time字段忽略**（用例要求：除time外其他字段需一致）
