## 🎯 使用示例

### 最简单的用法（推荐）⭐

```python
from test_cases.base_test import BaseTest

class MyTest(BaseTest):
    """我的测试用例"""

    @property
    def test_name(self):
        return "我的测试"

    def setup(self):
        """测试前置条件"""
        # 一行代码保存状态（自动恢复）
        self.save_test_environment()

    def execute(self):
        """执行测试"""
        # 随意修改PC网卡配置
        # 随意修改路由器配置
        # cleanup会自动恢复！
        pass

    def cleanup(self):
        """测试清理"""
        # 调用父类cleanup即可自动恢复
        super().cleanup()
```

### 高级用法

```python
def setup(self):
    """测试前置条件"""
    # 同时保存PC和路由器状态
    self.save_test_environment(
        save_pc_adapter=True,   # 保存PC网卡
        save_router=True,       # 保存路由器
        adapter_name="TEST"     # 网卡名称
    )
```

## 🔧 技术实现细节

### PC网卡状态保存

使用PowerShell获取网卡详细信息：
```powershell
Get-NetIPConfiguration -InterfaceAlias "TEST"
Get-NetIPInterface -InterfaceAlias "TEST" -AddressFamily IPv4
```

**保存内容**：
- DHCP启用状态 (`Dhcp` 属性)
- IPv4地址 (`IPv4Address`)
- 子网掩码 (从 `PrefixLength` 转换)
- 默认网关 (`IPv4DefaultGateway`)
- DNS服务器列表 (`DNSServer`)

### PC网卡状态恢复

根据保存的DHCP状态选择恢复方式：

**DHCP模式**：
```batch
netsh interface ip set address name="TEST" source=dhcp
netsh interface ip set dns name="TEST" source=dhcp
```

**静态IP模式**：
```batch
netsh interface ip set address name="TEST" static <IP> <Subnet> <Gateway>
netsh interface ip set dns name="TEST" static <DNS1>
netsh interface ip add dns name="TEST" <DNS2> index=2
```

### 异常处理

- ✅ 所有方法都有try-except异常捕获
- ✅ 失败时输出详细的错误信息和堆栈跟踪
- ✅ 部分失败不会中断测试流程

## 🎨 架构设计

### 职责分离

```
StateManager (状态管理器)
    ├── save_pc_adapter_state()      # PC网卡状态保存
    ├── restore_pc_adapter_state()   # PC网卡状态恢复
    ├── save_router_state()          # 路由器状态保存
    └── restore_router_state()       # 路由器状态恢复

BaseTest (测试基类)
    ├── save_test_environment()      # 调用StateManager保存
    ├── restore_test_environment()   # 调用StateManager恢复
    ├── set_auto_restore()           # 控制自动恢复
    └── cleanup()                    # 自动调用恢复

TestCase (具体测试用例)
    ├── setup()                      # 调用save_test_environment()
    ├── execute()                    # 执行测试
    └── cleanup()                    # 调用super().cleanup()
```

### 全局单例模式

`state_manager` 使用全局单例，所有测试用例共享同一个状态管理器实例：

```python
# utils/state_manager.py
state_manager = StateManager()  # 全局单例
```

**优点**：
- 简化调用：无需每次创建实例
- 状态共享：多个测试用例可以访问同一状态
- 内存高效：只有一个实例存在

## ⚙️ 配置选项

### 自动恢复控制

```python
# 启用自动恢复（默认）
self.set_auto_restore(True)

# 禁用自动恢复
self.set_auto_restore(False)
```

### 选择性保存

```python
# 只保存PC网卡
self.save_test_environment(save_pc_adapter=True, save_router=False)

# 只保存路由器
self.save_test_environment(save_pc_adapter=False, save_router=True)

# 同时保存两者
self.save_test_environment(save_pc_adapter=True, save_router=True)

# 指定网卡名称
self.save_test_environment(adapter_name="以太网")
```

## 🐛 已知限制

1. **路由器状态快照未实现**
   - 目前只保存路由器IP
   - WAN、Cellular、MQTT等配置快照待实现
   - 预留了扩展接口

2. **单网卡支持**
   - 当前只支持保存单个网卡状态
   - 多网卡场景需要多次调用

3. **权限要求**
   - 修改网卡配置需要管理员权限
   - 必须以管理员身份运行Flask服务

4. **Windows平台限制**
   - 使用Windows PowerShell和netsh命令
   - 不支持Linux/macOS（需要适配）
