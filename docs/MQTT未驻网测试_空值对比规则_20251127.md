# MQTT未驻网测试 - 空值对比规则优化

**文件**: `test_cases/mqtt_test/mqtt_cellular_status_unregistered_test.py`
**优化日期**: 2025-11-27
**优化目标**: 统一空值判断规则，双方都无数据时判定为一致

---

## 问题背景

在未驻网测试中，当页面和MQTT都无法获取到有效数据时（未注册状态），会出现各种形式的空值：
- 空字符串：`""`
- 短横线：`"-"` 或 `"--"`
- N/A标识：`"N/A"` 或 `"n.a."`
- 零值：`"0"`, `"0.0.0.0"`, `"::"`
- 其他：`"none"`, `"null"`

**原有问题**：
- 只在特定条件下（如未注册状态、APN断开）才允许空值
- 不同类型的空值（如 "-" vs "N/A"）被判定为不一致
- 导致测试失败，即使双方都确实没有数据

**优化目标**：
- ✅ 统一空值定义，涵盖所有可能的空值形式
- ✅ 只要双方都是空值，无论具体形式，都判定为一致
- ✅ 简化判断逻辑，移除复杂的状态检测

---

## 核心对比规则

### 规则定义

```
IF (MQTT值为空值) AND (页面值为空值) THEN
    判定结果 = 一致 ✅
ELSE IF (MQTT值 == 页面值) THEN
    判定结果 = 一致 ✅
ELSE
    判定结果 = 不一致 ✗
```

### 空值定义

| 数据类型 | 空值列表 |
|---------|---------|
| **通用** | `''`, `'n/a'`, `'--'`, `'-'`, `'none'`, `'null'`, `'n.a.'`, `'na'` |
| **IP地址** | 上述通用空值 + `'0.0.0.0'`, `'::'` |
| **流量统计** | 上述通用空值 + `'0 b'`, `'0b'` |

**注意**：所有对比都是**不区分大小写**的（转为小写后对比）

**代码位置**: 第610-675行

**修改前**：

```python
if unregistered_state and mqtt_field in optional_fields_when_unregistered:

if mqtt_is_empty and page_is_empty:
```

```python
    continue
```

**优化效果**：

- ✅ 移除了可选字段列表
- ✅ 所有字段统一使用空值判断
- ✅ 支持更多空值形式（如 `"-"` 和 `"N/A"` 都判定为空）

### 2. Network数据验证 (verify_network_data)

**代码位置**: 第677-759行

**修改前**：
```python
# 只在APN断开时，且是特定字段时，才允许空值
if apn_disconnected and mqtt_field in optional_fields_when_disconnected:
    if mqtt_is_empty and page_is_empty:
        print("APN断开，字段为空（正常）")
```

**修改后**：
```python
# 通用空值判断：只要MQTT和页面都是空值，就判定为一致
empty_values = ['', 'n/a', '--', '-', '0.0.0.0', '::', 'none', 'null', 'n.a.', 'na']
mqtt_is_empty = mqtt_value.lower() in empty_values
page_is_empty = page_value.lower() in empty_values

# 如果双方都为空，判定为一致（通过）
if mqtt_is_empty and page_is_empty:
    print(f"      ✓ {page_field}: 双方都无数据（空值一致）")
    continue
```

**优化效果**：
- ✅ 移除了APN断开状态检测
- ✅ 移除了可选字段列表
- ✅ 所有字段统一使用空值判断
- ✅ 增加IP地址相关的空值（`0.0.0.0`, `::`）

**对比字段**（8个/APN × 3个APN = 24个）：
```
status, ip, gate, dns, ipv6, gatev6, dnsv6, time
```

**特殊处理**：
1. **IPv4处理**：页面可能包含子网掩码（如 `10.0.0.1/24`），先去除 `/24` 再判断
2. **IPv6处理**：MQTT和页面都可能包含前缀长度（如 `/64`），先去除再对比
3. **DNS处理**：页面可能有多个DNS（如 `8.8.8.8, 8.8.4.4`），只取第一个
4. **时间处理**：允许60秒的时间差（因为获取页面和MQTT响应有时间间隔）

## 对比流程图

```
开始对比字段值
    ↓
提取MQTT值和页面值
    ↓
特殊处理（去子网掩码/前缀长度/多DNS等）
    ↓
判断：双方都为空值？
    ├─ YES → ✅ 输出"双方都无数据（空值一致）" → 继续下一个字段
    └─ NO  → 继续
         ↓
    判断：值是否相等？
         ├─ YES → ✅ 输出"MQTT=\"xxx\" 页面=\"xxx\"" → 继续下一个字段
         └─ NO  → ✗ 输出"不一致" + 详细值 → 标记测试失败
              ↓
         继续下一个字段
```

## 空值支持列表

### 通用空值（所有字段）

| 空值形式 | 说明 | 示例场景 |
|---------|------|---------|
| `''` | 空字符串 | MQTT未返回该字段 |
| `'n/a'` | 不可用 | 页面显示"N/A" |
| `'n.a.'` | 不可用（带点） | 页面显示"N.A." |
| `'na'` | 不可用（缩写） | 简化显示 |

| `'-'` | 单横线 | 页面显示"-" |
| `'0'` | 数字零 | LAC/Cell ID为0 |
| `'none'` | 无 | 某些固件版本 |
| `'null'` | 空值 | JSON null值 |

## 注意事项

### 1. 空值判断的时机
空值判断必须在**特殊处理之后**进行，例如：
- IPv4去除子网掩码后再判断（`10.0.0.1/24` → `10.0.0.1`）
- IPv6去除前缀长度后再判断（`fe80::1/64` → `fe80::1`）
- DNS取第一个后再判断（`8.8.8.8, 8.8.4.4` → `8.8.8.8`）

### 2. 不区分大小写
所有对比都转为小写后进行：
- `"N/A"` 和 `"n/a"` 都被视为空值
- `"None"` 和 `"none"` 都被视为空值

### 3. 空值不等于零值
以下情况**不判定为一致**：
- MQTT: `""` (空) vs 页面: `"10.0.0.1"` (有值) → ✗ 不一致
- MQTT: `"Ready"` (有值) vs 页面: `"--"` (空) → ✗ 不一致

### 4. 时间字段特殊处理
Connection Duration字段即使有值也允许60秒误差：
- MQTT: `"0 days, 11:52:03"` vs 页面: `"0 days, 11:52:45"` → ✓ 一致（差42秒）
- MQTT: `""` vs 页面: `""` → ✓ 一致（都为空）
