# 固件上传流程修复 - 补充修复

**修复时间**: 2025-12-02 20:15
**问题**: 文件选择后卡住，未点击升级按钮
**严重级别**: 🔴 阻塞（100%卡住）

---

## 问题分析

### 用户反馈
> "上传后卡住上传弹出的界面，然后没有点击确定上传"

### 根本原因

**错误理解了上传流程**：

```
❌ 原以为的流程：
1. 选择文件 → 2. 文件自动上传 → 3. 点击升级按钮

✅ 实际的流程：
1. 选择文件 → 2. 点击升级按钮 → 3. 文件开始上传 → 4. 自动升级
```

**代码问题**：
1. 在选择文件后就开始等待上传（实际文件还没上传）
2. 等待时间浪费在错误的位置
3. 点击升级按钮后没有等待上传完成

---

## 修复方案

### 1. 调整等待逻辑位置

**修复前**（错误）：
```python
# 步骤3: 选择文件
pyautogui.press('enter')

# ❌ 步骤3.5: 等待文件上传（错误！文件还没开始上传）
time.sleep(30)  # 浪费时间

# 步骤4: 点击升级按钮
upgrade_btn.click()
# 问题：点击后立即进入下一步，实际文件才开始上传
```

**修复后**（正确）：
```python
# 步骤3: 选择文件
pyautogui.press('enter')
time.sleep(3)  # 只等待对话框关闭

# 步骤3.5: 验证文件路径（确保对话框已关闭）
file_value = upload_input.get_attribute("value")
assert filename in file_value

# 步骤4: 点击升级按钮
upgrade_btn.click()

# ✅ 步骤4.5: 等待文件上传（正确！现在文件才开始上传）
time.sleep(estimated_upload_time)  # 根据文件大小计算
```

### 2. 增加对话框关闭等待时间

```python
# 修复前
pyautogui.press('enter')
time.sleep(2)  # 可能不够

# 修复后
pyautogui.press('enter')
time.sleep(3)  # 增加到3秒，确保对话框完全关闭
```

### 3. 增加文件路径验证

```python
# 新增：验证文件路径已填充
upload_input = self.driver.find_element(By.XPATH, '//*[@id="1_file_url"]')

max_wait = 10
for i in range(max_wait):
    file_value = upload_input.get_attribute("value")
    if file_value and filename in file_value:
        print(f"✅ 文件路径已显示: {file_value}")
        break
    time.sleep(1)
else:
    print(f"❌ 文件路径未显示，文件选择失败")
    return False
```

### 4. 优化上传时间计算

```python
# 修复前
estimated_upload_time = max(5, int(file_size_mb / 1.5))  # 不够保守

# 修复后
estimated_upload_time = max(10, int(file_size_mb / 1.0))  # 按1MB/s计算，至少10秒
```

### 5. 增加处理等待时间

```python
# 点击升级按钮后
upgrade_btn.click()

# 等待上传
time.sleep(estimated_upload_time)

# 新增：额外等待5秒确保路由器开始处理
time.sleep(5)
```

    pyautogui.press('enter')
    time.sleep(3)  # ✅ 等待对话框关闭

    # 3.5. 验证文件路径（新增）
    for i in range(10):
        file_value = upload_input.get_attribute("value")
        if file_value and filename in file_value:
            break
        time.sleep(1)
    else:
        return False  # ✅ 验证失败则退出

    # 4. 点击升级按钮
    upgrade_btn.click()

    # 4.5. 等待文件上传（修复位置）✅
    file_size_mb = os.path.getsize(firmware_path) / 1024 / 1024
    upload_time = max(10, int(file_size_mb / 1.0))  # ✅ 更保守的估算

    for i in range(upload_time):
        progress = int((i / upload_time) * 100)
        print(f"上传进度: {progress}% ... 剩余 {upload_time - i} 秒", end='\r')
        time.sleep(1)

    time.sleep(5)  # ✅ 额外等待路由器处理
