## 原始成功实现的核心机制


2. **后台持续读取** (第279-335行)

## 如果v3仍然失败怎么办？

如果固定等待60秒仍然失败（脚本输出还是只有一个字符），说明问题不在超时判断，而在于：

1. **路由器上的Python脚本本身有问题**
   - 语法错误
   - 依赖缺失
   - 权限问题

2. **串口通信机制有问题**
   - 串口被占用
   - 波特率不匹配
   - 数据丢失

3. **需要采用原始实现的后台线程机制**
   - 创建独立的串口读取线程
   - 使用队列存储数据
   - 主线程从队列获取数据
