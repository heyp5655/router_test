# 串口日志记录功能实现总结

**实现时间**: 2025-12-03
**功能**: 为串口通信添加完整的实时日志记录

---

## 📋 功能概述

为 `utils/serial_client.py` 添加了**完整的串口日志记录功能**，实现以下特性：

### 核心特性

1. **✅ 实时日志记录** - 所有串口通信实时记录到文件
2. **✅ 自动创建日志文件** - 按COM端口和时间戳命名
3. **✅ 自动刷新到磁盘** - buffering=1 确保实时写入
4. **✅ 密码隐藏** - 日志中自动隐藏敏感信息
5. **✅ 详细时间戳** - 毫秒级时间戳（精确到毫秒）
6. **✅ 分类标记** - SEND/RECV/INFO/ERROR 清晰标记
7. **✅ 异常安全** - 日志失败不影响主流程

## 🔐 密码隐藏机制

### 自动隐藏密码

所有包含密码的日志会自动隐藏：

```python
# 串口登录密码
self.password = "R0uT3&U&s@l1nk46#3"
# 日志中显示为: ***PASSWORD***

# Boot模式密码
self.boot_password = "ys23#2ls29#4"
# 日志中显示为: ***BOOT_PASSWORD***
```

### 实现代码

```python
def _log_send(self, data: str):
    """记录发送的数据"""
    # 隐藏密码
    display_data = data
    if self.password in data:
        display_data = data.replace(self.password, "***PASSWORD***")
    if self.boot_password in data:
        display_data = display_data.replace(self.boot_password, "***BOOT_PASSWORD***")

    self._write_log(display_data, "SEND")
```

## 🛠️ 使用方法

### 基本使用

```python
from utils.serial_client import SerialClient

# 创建串口客户端（自动创建日志文件）
client = SerialClient("COM7")

# 打开串口（记录到日志）
client.open()

# 执行操作（所有操作自动记录）
client.login()

client.close()
```

## 📂 日志管理

### 清理旧日志

```python
import os
import glob
from datetime import datetime, timedelta

def cleanup_old_logs(days=7):
    """删除7天前的日志"""
    log_dir = "logs/serial"
    cutoff_date = datetime.now() - timedelta(days=days)

    for log_file in glob.glob(os.path.join(log_dir, "*.log")):
        file_time = datetime.fromtimestamp(os.path.getctime(log_file))
        if file_time < cutoff_date:
            os.remove(log_file)
            print(f"删除旧日志: {log_file}")
```

### 日志压缩

```python
import gzip
import shutil

def compress_log(log_file):
    """压缩日志文件"""
    with open(log_file, 'rb') as f_in:
        with gzip.open(f"{log_file}.gz", 'wb') as f_out:
            shutil.copyfileobj(f_in, f_out)
    os.remove(log_file)
```

## ⚠️ 注意事项

### 1. 磁盘空间

- 1000次循环约产生10MB日志
- 长期测试需注意磁盘空间
- 建议定期清理旧日志

### 2. 日志文件句柄

- 日志文件在 `close()` 时自动关闭
- 异常退出可能导致文件未关闭
- 建议使用 try-finally 确保关闭

```python
client = SerialClient("COM7")
try:
    client.open()
    # 执行操作
finally:
    client.close()  # 确保关闭日志
```

### 3. 多进程并发

- 每个串口独立的日志文件
- COM7和COM8的日志不会冲突
- 线程安全（每个线程操作独立文件）

### 4. 日志刷新

```python
# 日志文件使用 buffering=1 (行缓冲)
self.log_file = open(..., buffering=1)

# 每写入一行自动flush，确保实时性
self.log_file.write(log_line + "\n")
self.log_file.flush()  # 显式flush，双重保险
```
