#### 静态保留端口列表

RESERVED_PORTS = [

#### 测试流程
1. **前置条件**:
   - 设备出厂状态
   - 登录路由器Web界面

2. **测试执行**:
   - 跳转到端口映射页面 (`#network/firewall/portmapping`)
   - 遍历端口 1-65535（共65535个端口）
   - 对每个端口进行测试:
     - 添加端口映射规则
     - 保存并检查是否有冲突弹窗
     - 判断测试结果

3. **判断逻辑**:
   - **保留端口**: 应该弹出冲突提示 → ✅ 有弹窗=通过，❌ 无弹窗=失败
   - **非保留端口**: 不应该弹出冲突提示 → ✅ 无弹窗=通过，❌ 有弹窗=失败

4. **测试统计**:
   - 总端口数: 65535
   - 已测试数、通过数、失败数
   - 失败端口列表
   - 成功率计算

### 3. RouterClient新增方法

#### `add_port_mapping()` - 添加端口映射
```python
def add_port_mapping(self, src: str, dst_ip: str, dst_port: str, external_port: str) -> bool
```
- 功能: 添加端口映射规则
- 参数:
  - `src`: 源地址 (例如: "192.168.1.100/24")
  - `dst_ip`: 目标IP (例如: "10.10.10.10")
  - `dst_port`: 目标端口 (例如: "111")
  - `external_port`: 外部端口（要测试的端口号）
- 返回: True=成功, False=失败

#### `save_and_check_popup()` - 保存并检查弹窗
```python
def save_and_check_popup(self) -> bool
```
- 功能: 点击保存按钮并检查是否有端口冲突弹窗
- 返回: True=有弹窗（端口冲突），False=无弹窗（端口可用）

### ✅ 优点
1. **全面覆盖**: 测试所有65535个端口
2. **精确验证**: 保留端口列表与研发提供的完全一致
3. **详细报告**: 显示测试进度、统计信息、失败端口列表
