# 测试状态管理使用指南

## 概述

测试框架现在支持**自动保存和恢复测试环境状态**，确保测试完成后PC网卡和路由器配置能够恢复到测试前的状态。

## 核心功能

### 1. PC网卡状态管理
- ✅ 自动保存DHCP/静态IP配置
- ✅ 自动保存IP地址、子网掩码、网关
- ✅ 自动保存DNS服务器
- ✅ 测试完成后自动恢复

### 2. 路由器配置状态管理
- ✅ 保存路由器IP
- ⚠️  详细配置快照功能待实现（WAN、Cellular、MQTT等）

## 使用方法

### 方法1：自动模式（推荐）⭐

在测试用例的 `setup()` 方法中调用 `save_test_environment()`，框架会自动在 `cleanup()` 中恢复状态。

```python
from test_cases.base_test import BaseTest

class MyTest(BaseTest):
    """我的测试用例"""

    @property
    def test_name(self):
        return "我的测试"

    def setup(self):
        """测试前置条件"""
        print(f"\n{'='*70}")
        print(f"测试前置条件: {self.test_name}")
        print(f"{'='*70}\n")

        # 保存测试环境状态（自动恢复）
        self.save_test_environment(
            save_pc_adapter=True,  # 保存PC网卡状态
            save_router=False,     # 是否保存路由器状态
            adapter_name="TEST"    # 网卡名称
        )

        # 其他前置条件...

    def execute(self):
        """执行测试"""
        # 测试步骤可以修改PC网卡配置
        # 测试步骤可以修改路由器配置
        # 不用担心，cleanup会自动恢复！
        pass

    def cleanup(self):
        """测试清理"""
        # 调用父类的cleanup，自动恢复状态
        super().cleanup()

        # 其他清理工作...
```

### 方法2：手动模式

如果需要更精细的控制，可以手动调用恢复方法：

```python
def cleanup(self):
    """测试清理"""
    print(f"\n{'='*70}")
    print(f"测试清理")
    print(f"{'='*70}\n")

    # 手动恢复状态
    self.restore_test_environment()

    # 其他清理工作...
    print("测试清理完成")
```

### 方法3：禁用自动恢复

如果某些测试不需要自动恢复：

```python
def setup(self):
    """测试前置条件"""
    # 禁用自动恢复
    self.set_auto_restore(False)

    # 保存状态（但不会自动恢复）
    self.save_test_environment()
```

## API参考

### BaseTest 方法

#### `save_test_environment(save_pc_adapter=True, save_router=False, adapter_name="TEST")`

保存测试环境状态

**参数：**
- `save_pc_adapter` (bool): 是否保存PC网卡状态，默认True
- `save_router` (bool): 是否保存路由器配置状态，默认False
- `adapter_name` (str): PC网卡名称，默认"TEST"

**返回：**
- `bool`: 保存是否成功

**示例：**
```python
# 只保存PC网卡
self.save_test_environment()

# 同时保存PC网卡和路由器
self.save_test_environment(save_pc_adapter=True, save_router=True)

# 指定网卡名称
self.save_test_environment(adapter_name="以太网")
```

#### `restore_test_environment()`

恢复测试环境到之前保存的状态

**返回：**
- `bool`: 恢复是否成功

**示例：**
```python
# 手动恢复
self.restore_test_environment()
```

#### `set_auto_restore(enabled)`

设置是否启用自动恢复

**参数：**
- `enabled` (bool): True启用，False禁用

**示例：**
```python
# 禁用自动恢复
self.set_auto_restore(False)

# 启用自动恢复
self.set_auto_restore(True)
```

## 实际应用示例

### 示例1：WAN测试 - 修改PC网卡为静态IP

```python
class WanStaticIPTest(BaseTest):
    """WAN静态IP测试"""

    def setup(self):
        """测试前置条件"""
        # 保存PC网卡当前状态（可能是DHCP）
        self.save_test_environment(adapter_name="TEST")

    def execute(self):
        """执行测试"""
        from utils.network_utils import network_utils

        # 设置PC网卡为静态IP进行测试
        network_utils.set_adapter_static_ip(
            adapter_name="TEST",
            ip="192.168.1.100",
            subnet="255.255.255.0",
            gateway="192.168.1.1"
        )

        # 进行WAN测试...

    def cleanup(self):
        """测试清理"""
        # 自动恢复PC网卡到之前的DHCP状态
        super().cleanup()
```

## 注意事项

1. **管理员权限**：修改网卡配置需要管理员权限，确保Flask服务以管理员身份运行

2. **网卡名称**：默认使用"TEST"，确保该网卡存在，或传入正确的网卡名称

3. **状态保存时机**：建议在 `setup()` 方法开始时就保存状态

4. **异常处理**：即使测试失败或抛出异常，`cleanup()` 也会被调用并恢复状态

5. **路由器状态**：路由器详细配置快照功能待实现，目前只保存基础信息

## 故障排查

### 问题1：恢复失败 - "需要管理员权限"

**原因**：修改网卡配置需要管理员权限

**解决**：
```bash
# 使用管理员身份启动Flask服务
start_admin.bat
```

### 问题2：网卡名称错误

**错误信息**：`❌ 获取网卡信息失败`

**解决**：
```python
# 检查网卡名称
ipconfig

# 使用正确的网卡名称
self.save_test_environment(adapter_name="以太网")
```

### 问题3：状态未恢复

**原因**：可能没有调用父类的 `cleanup()`

**解决**：
```python
def cleanup(self):
    # 确保调用父类的cleanup
    super().cleanup()

    # 其他清理工作...
```
