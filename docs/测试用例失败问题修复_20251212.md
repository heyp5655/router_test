# Python第三方库测试用例失败问题修复说明

**修复日期**: 2025-12-12
**影响用例**:
- paho-mqtt库验证测试
- pymodbus库验证测试
- pyserial库验证测试

## 问题现象

3个Python第三方库测试用例全部失败，表现为：

1. 路由器端Python脚本执行后**立即结束**（超过10秒未收到数据）
2. 串口捕获的**输出几乎为空**（只有 'e', 'ey' 等几个字符）
3. 测试结果解析失败，无法找到"✅ 所有测试通过！"标记
4. **以前曾经成功过，现在失败了**

## 根本原因

### 核心问题：Python stdout缓冲机制

当Python脚本通过串口执行时，**stdout默认使用全缓冲模式（fully buffered）**：

- 非交互式终端（如串口、管道）：全缓冲（缓冲区满了才输出，通常8KB）
- print语句的输出会被缓存在内存中，不会立即发送到串口
- 测试框架等待超时（20秒），误以为脚本已结束

## 解决方案

在3个测试文件中，为Python执行命令添加 **`-u` 参数**（unbuffered mode）：

### 修改前
```python
command = f"export LD_LIBRARY_PATH={lib_path}:$LD_LIBRARY_PATH && {python_path} {script_path} 2>&1\n"
```

### 修改后
```python
# 添加 -u 参数：unbuffered模式，确保print立即输出到串口
command = f"export LD_LIBRARY_PATH={lib_path}:$LD_LIBRARY_PATH && {python_path} -u {script_path} 2>&1\n"
```

### 修改的文件

1. **test_cases/app_tests/paho_mqtt_library_test.py** - 第639行
2. **test_cases/app_tests/pymodbus_library_test.py** - 第650行
3. **test_cases/app_tests/pyserial_library_test.py** - 第631行、第933行

## Python -u 参数的作用

- 强制 unbuffered模式
- print语句**立即输出**，不等待换行符或缓冲区满
- 等同于设置环境变量 `PYTHONUNBUFFERED=1`
