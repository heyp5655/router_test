```python
def upload_and_upgrade_firmware(self, firmware_path: str, timeout: int = 300) -> bool:
    # 1. 检查固件文件
    if not os.path.exists(firmware_path):
        return False

    # 2. 跳转到升级页面
    upgrade_url = f"http://{self.router_ip}/#maintenance/upgrade/upgrade"
    self.driver.get(upgrade_url)

    # 3. 上传固件
    upload_input = self.wait.until(
        EC.presence_of_element_located((By.XPATH, '//*[@id="1_file_url"]'))
    )
    upload_input.send_keys(firmware_path)

    # 4. 点击升级按钮
    upgrade_btn = self.wait.until(
        EC.element_to_be_clickable((By.XPATH, '//*[@id="1_file_import"]'))
    )
    upgrade_btn.click()

    # 5. 等待重启并重新登录
    self.driver.quit()
    self.driver = None
    time.sleep(60)  # 等待路由器开始重启

    # 6. 尝试重新登录
    while retry_count < max_retries:
        if self.login_web(max_retries=1):
            return True
        time.sleep(10)

    return False
```

### 2. 串行 vs 并行
**当前实现**: 串行执行（先测设备1，再测设备2）

**原因**:
- 简化实现，避免多线程复杂性
- 减少资源竞争（浏览器驱动）
- 便于日志输出和调试

**如需并行执行**:
```python
import threading

def test_device_thread(device_client, device_name, ...):
    self._test_device_upgrade_cycles(...)

# 创建线程
t1 = threading.Thread(target=test_device_thread, args=(device1_client, "设备1", ...))
t2 = threading.Thread(target=test_device_thread, args=(device2_client, "设备2", ...))

# 启动线程
t1.start()
t2.start()

# 等待完成
t1.join()
t2.join()
```

### 3. 测试时长预估
假设每次升级需要3分钟：
- 每次循环: 2次升级 × 3分钟 = 6分钟
- 1000次循环: 6分钟 × 1000 = 6000分钟 = 100小时
- 两台设备（串行）: 100小时 × 2 = 200小时 = 8.3天

**建议**:
- 先小规模测试（10次循环）
- 验证功能正常后再运行完整测试
- 考虑分批次执行（每次100循环）
