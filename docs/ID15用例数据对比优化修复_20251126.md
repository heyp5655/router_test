## 🐛 发现的问题

### 问题 1: modem_status 数据源错误 ❌

**问题描述**:
- `modem_status` 应该和 `#status/summary` 页面的蜂窝状态对比
- 之前代码从 `#status/cellular` 的详细页面获取 `Status` 字段
- 两个页面的 `Status` 字段内容不同：
  - **Summary 页面**: `"Ready, FDD LTE,"` (包含网络类型)
  - **Detail 页面**: `"Ready, FDD LTE,"` (可能格式不同)

**影响**:
- MQTT的 `modem_status` 字段对比失败
- 即使数据正确也会报错

### 问题 3: 打印输出缺少页面数据 ❌

**问题描述**:

### 修复 1: 获取 Summary 页面的 Status

**修改文件**: `test_cases/mqtt_test/mqtt_cellular_status_report_test.py:267-302`

**修复代码**:
```python
def get_page_cellular_data(self):
    """获取页面蜂窝状态数据"""
    try:
        # 1. 获取详细页面数据
        detail_result = self.router_client.check_cellular_detail_status(timeout=30)
        if not detail_result['success']:
            return None

        # 2. 获取 summary 页面的状态（用于 modem_status 对比）
        summary_result = self.router_client.check_cellular_summary_status(timeout=30)
        if not summary_result['success']:
            return None

        # 3. 合并数据：detail为主，添加 Summary Status 字段
        detail_result['Summary Status'] = summary_result['Status']

        print("  ✅ 成功获取页面蜂窝状态数据")
        print(f"  Summary Status: {summary_result['Status']}")
        print(f"  Detail Status: {detail_result.get('Status', 'N/A')}")

        return detail_result
    except Exception as e:
        print(f"  ✗ 获取页面蜂窝状态异常: {e}")
        return None
```

**修复说明**:
1. 调用两个函数获取数据：
   - `check_cellular_detail_status()` - 获取详细数据
   - `check_cellular_summary_status()` - 获取概览状态
2. 将 Summary 的 `Status` 存储为 `Summary Status`
3. 在对比时使用 `Summary Status` 而不是 `Status`
4. 打印两个状态值以便调试
