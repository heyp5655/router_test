## 技术总结

### 前端分类树工作原理

1. **定义树结构** (硬编码):
   ```javascript
   var treeStructure = [ ... ];
   ```

2. **分配测试用例** (动态):
   ```javascript
   node.testCases = this.testCases.filter(tc => tc.category === node.path);
   ```

3. **匹配规则**:
   - 测试用例的 `category` 必须**完全匹配**树节点的 `path`
   - 例: `category: "功能用例/端口冲突检测"` 匹配 `path: "功能用例/端口冲突检测"`

### 为什么用硬编码？

- **UI结构稳定**: 分类层级固定，不常变化
- **性能优化**: 不需要每次动态计算树结构
- **自定义排序**: 可以手动控制分类显示顺序

### 添加新分类的步骤

1. **后端**: 测试用例定义完整的 `category` 路径
2. **前端**: 在 `buildTestTree()` 中添加对应的树节点
3. **刷新浏览器**: 查看效果
