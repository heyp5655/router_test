# 固件版本检查优化 - 自动跳转首页

**日期**: 2025-12-10
**版本**: v1.0
**问题**: 循环 1 失败: 新版本号验证失败，不是 32.3.0.9

---

## 🐛 问题分析

### 用户反馈
```
循环 1 失败: 新版本号验证失败，不是 32.3.0.9
```

### 根本原因

#### 1. **缺少页面跳转**
- `check_firmware_version()` 方法直接查找版本号元素
- 没有先跳转到包含版本号的页面
- 登录成功后可能停留在任意页面，不一定在首页

#### 2. **版本号元素位置**
- 元素 XPath: `//*[@id="qwert_firmware_ver"]`
- 该元素**只在首页（#status/summary）上存在**
- 如果当前页面不是首页，找不到该元素

#### 3. **登录后的页面状态**
```
login_web_force() 成功
    → _verify_login_success() 验证成功
    → 但停留在哪个页面？不确定！

可能的页面:
1. #status/summary（首页）
2. #network/interfaces/wan（网络配置页）
3. #system/administration（系统配置页）
4. 其他任意页面
```

### 失败流程

```
步骤9: Web重新登录成功
    → 登录后停留在某个页面（可能不是首页）

步骤10: 验证新版本号
    → check_firmware_version("32.3.0.9")
    → 查找元素 //*[@id="qwert_firmware_ver"]
    → ❌ 找不到元素（因为不在首页）
    → 或者找到其他页面的同名元素（内容不对）
    → ❌ 版本号不匹配
```

## 📝 修改详情

### 修改前代码

```python
def check_firmware_version(self, expected_version: str) -> bool:
    """检查首页的固件版本号"""
    try:
        print(f"检查固件版本号...")

        # ❌ 没有跳转页面，直接查找元素
        version_xpath = '//*[@id="qwert_firmware_ver"]'
        version_element = self.wait.until(
            EC.presence_of_element_located((By.XPATH, version_xpath))
        )

        actual_version = version_element.text.strip()

        if actual_version == expected_version:
            print(f"✅ 版本号匹配: {actual_version}")
            return True
        else:
            print(f"❌ 版本号不匹配！")
            return False

    except Exception as e:
        print(f"❌ 检查版本号失败: {e}")
        return False
```

**问题**:
- 没有跳转到首页
- 日志信息不够详细
- 版本号不匹配时没有详细信息

### 修改后代码

```python
def check_firmware_version(self, expected_version: str, skip_navigation: bool = False) -> bool:
    """
    检查首页的固件版本号

    Args:
        expected_version: 期望的版本号（如 "32.3.0.7"）
        skip_navigation: 是否跳过导航到首页（默认False，会自动跳转到 #status/summary）

    Returns:
        bool: 版本号匹配返回True
    """
    try:
        print(f"\n{'='*60}")
        print(f"检查固件版本号...")
        print(f"{'='*60}")

        # ✅ 关键：先跳转到首页（status/summary），确保版本号元素可见
        if not skip_navigation:
            print(f"步骤1: 导航到首页 #status/summary")
            status_url = f"http://{self.router_ip}/#status/summary"
            self.driver.get(status_url)
            time.sleep(2)
            self.driver.refresh()
            time.sleep(3)
            print(f"  ✅ 已跳转到首页")
            print(f"  当前URL: {self.driver.current_url}")
        else:
            print(f"  ℹ️  跳过导航，使用当前页面")
            print(f"  当前URL: {self.driver.current_url}")

        # 步骤2: 查找版本号元素
        version_xpath = '//*[@id="qwert_firmware_ver"]'
        print(f"\n步骤2: 查找版本号元素: {version_xpath}")

        version_element = self.wait.until(
            EC.presence_of_element_located((By.XPATH, version_xpath))
        )

        # 步骤3: 获取版本号文本
        actual_version = version_element.text.strip()
        print(f"\n步骤3: 对比版本号")
        print(f"  期望版本: {expected_version}")
        print(f"  实际版本: {actual_version}")
        print(f"  版本号长度: 期望={len(expected_version)}, 实际={len(actual_version)}")

        # 步骤4: 对比版本号
        if actual_version == expected_version:
            print(f"\n✅ 版本号匹配: {actual_version}")
            return True
        else:
            print(f"\n❌ 版本号不匹配！")
            print(f"   期望: '{expected_version}'")
            print(f"   实际: '{actual_version}'")

            # 详细对比（逐字符）
            print(f"\n详细对比（逐字符）:")
            max_len = max(len(expected_version), len(actual_version))
            for i in range(max_len):
                expected_char = expected_version[i] if i < len(expected_version) else '(无)'
                actual_char = actual_version[i] if i < len(actual_version) else '(无)'
                match = '✓' if expected_char == actual_char else '✗'
                print(f"   位置 {i}: 期望='{expected_char}' 实际='{actual_char}' {match}")

            return False

    except Exception as e:
        print(f"\n❌ 检查版本号失败: {e}")
        print(f"   当前URL: {self.driver.current_url}")
        import traceback
        traceback.print_exc()
        return False
```

**改进**:
- ✅ 自动跳转到首页 `#status/summary`
- ✅ 详细的步骤日志（步骤1-4）
- ✅ 显示当前URL、版本号长度
- ✅ 逐字符对比版本号（便于调试）

## 🔍 技术细节

### 版本号元素定位

**XPath**: `//*[@id="qwert_firmware_ver"]`

**位置**: 首页（#status/summary）

**HTML结构示例**:
```html
<div id="status_summary">
  <div class="device-info">
    <label>固件版本</label>
    <label id="qwert_firmware_ver">32.3.0.9</label>
  </div>
</div>
```

---

### 跳转时序

```
1. driver.get("http://192.168.3.7/#status/summary")  # 跳转
2. time.sleep(2)                                      # 等待加载
3. driver.refresh()                                   # 刷新页面
4. time.sleep(3)                                      # 等待稳定
5. 查找版本号元素                                    # 元素查找
```

**总耗时**: 约5-6秒

---

### 版本号对比逻辑

**方法**: 字符串精确匹配 `==`

**示例**:
```python
expected = "32.3.0.9"
actual = "32.3.0.7"

# 精确匹配
if actual == expected:  # False（不匹配）
    return True
```

**注意**:
- 不支持模糊匹配
- 不支持正则表达式
- 区分大小写
- 前后空格会被 `strip()` 移除
