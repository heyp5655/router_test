## 关键元素定位

### 防火墙Security
- FTP端口: `//*[@id="1_ftp_port"]`
- FTP启用: `//*[@id="1_ftp_local"]`
- 保存: `//*[@id="save"]`
- 应用: `//*[@id="apply"]`

### 端口映射
- 添加按钮: `//*[@id="mapping_operate"]`
- 源地址: `//input[contains(@id, "_src")]`
- 目标IP: `//input[contains(@id, "_to_dst")]`
- 目标端口: `//input[contains(@id, "_to_dport")]`
- 测试端口: `//input[contains(@id, "_dport") and not(contains(@id, "_to_dport"))]`

### Serial1/2
- 启用: `//*[@id="1_enable"]`
- 模式: `//*[@id="1_mode"]` (value="1" for DTU Mode)
- 协议: `//*[@id="1_protocol"]` (value="3" for TCP Server)
- 端口: `//*[@id="1_local_port_2"]` (TCP/UDP Server)

### SNMP
- 启用: `//*[@id="1_enable"]`
- 端口: `//*[@id="1_port"]`

### GPS
- GPS启用: `//*[@id="1_enable"]` (#industrial/gps/gps)
- IP Forwarding启用: `//*[@id="1_enable"]` (#industrial/gps/ipforwarding)
- 类型: `//*[@id="1_type"]` (value="server")
- 本地端口: `//*[@id="1_local_port"]`

## 冲突弹窗检测

所有测试用例使用统一的弹窗检测逻辑：

```python
has_conflict_popup = False
try:
    ok_button = WebDriverWait(self.router_client.driver, 3).until(
        EC.element_to_be_clickable((By.XPATH, '/html/body/div[13]/div/div[3]/button'))
    )
    has_conflict_popup = True

    # 获取弹窗文本
    popup_text = self.router_client.driver.find_element(
        By.XPATH, '/html/body/div[13]/div/div[2]'
    ).text

    # 点击OK关闭
    ok_button.click()

except TimeoutException:
    has_conflict_popup = False
```
