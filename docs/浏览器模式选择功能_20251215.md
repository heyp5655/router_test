# 浏览器模式选择功能 - 2025-12-15

## 🎯 功能说明

**需求**: 添加浏览器模式选择，支持无痕模式和普通模式，更好地模拟真实用户使用场景。

**背景**:
- **无痕模式**：干净的测试环境，没有缓存、cookies等干扰，适合自动化测试
- **普通模式**：保留缓存、cookies，更接近真实用户使用场景，能发现缓存相关问题

**用户反馈**:
> "默认用无痕模式，如果指定了也可以用普通的模式更能发现问题，因为客户不会用无痕模式"

---

## 📋 功能特性

### 1. 默认使用无痕模式

**原因**:
- ✅ 确保每次测试环境一致
- ✅ 避免缓存干扰测试结果
- ✅ 更可靠的自动化测试

### 2. 可选普通模式

**原因**:
- ✅ 模拟真实用户使用场景
- ✅ 发现缓存相关问题
- ✅ 测试Session持久化功能
- ✅ 验证Cookie处理逻辑

### 3. 灵活配置

**配置方式**:
- Web UI配置
- 测试用例配置
- 命令行参数（如需要）

## 📊 两种模式对比

### 无痕模式（Incognito Mode）

**特点**:
- ✅ 不保存浏览历史
- ✅ 不保存Cookies
- ✅ 不保存缓存文件
- ✅ 不保存表单数据
- ✅ 每次测试环境一致

**适用场景**:
- 自动化测试（推荐）
- 回归测试
- 稳定性测试
- 需要干净环境的测试

**Chrome参数**: `--incognito`

### 普通模式（Normal Mode）

**特点**:
- ✅ 保存浏览历史
- ✅ 保存Cookies
- ✅ 保存缓存文件
- ✅ 保存表单数据
- ✅ 更接近真实用户场景

**适用场景**:
- 缓存功能测试
- Session持久化测试
- Cookie功能测试
- 性能测试（缓存命中）
- 真实用户场景模拟

**Chrome参数**: 无（默认行为）

## 🎯 应用场景

### 场景1: 日常自动化测试

**推荐模式**: 无痕模式（默认）

**原因**:
- 确保测试环境一致
- 避免缓存干扰
- 提高测试可靠性

### 场景2: 缓存问题排查

**推荐模式**: 普通模式

**示例**:
```python
# 测试缓存导致的问题
config = RouterConfig(
    router_ip="192.168.1.1",
    username="admin",
    password="password",
    model="UR35",
    incognito_mode=False  # 使用普通模式
)
```

**可能发现的问题**:
- 缓存的配置页面数据导致表单预填充错误
- 旧版本的JavaScript文件被缓存
- Cookie过期处理不当
- Session管理问题

### 场景3: 稳定性测试

**推荐模式**: 无痕模式

**原因**:
- 100次循环测试需要环境一致
- 避免缓存累积导致的问题
- 更容易复现问题

**示例**: ID41测试用例
```python
# 默认使用无痕模式
self.router_client = RouterClient(self.config.router_config)
```

### 场景4: 性能测试

**推荐模式**: 普通模式

**原因**:
- 测试缓存命中率
- 模拟真实用户体验
- 测试资源加载时间
