## 根本原因

## 解决方案

### 方案1: 手动重启Flask（推荐）

**步骤1: 结束当前Flask进程**

打开**任务管理器** (Ctrl + Shift + Esc):
1. 找到 "详细信息" 标签
2. 找到 `python.exe` 进程 (PID: 17420)
3. 右键 → 结束任务

或使用**管理员CMD**:
```cmd
taskkill /F /PID 17420
```

**步骤2: 重新启动Flask**

在项目目录打开**管理员CMD**:
```cmd
cd E:\GIT\ROUTER_TEST
python app.py
```

或双击启动脚本:
```
start_admin.bat
```

**步骤3: 验证**
1. 浏览器访问: http://localhost:5000
2. 查看"测试用例"页面
3. 应该能看到: **功能用例** 分类
4. 测试用例: **端口冲突检测测试**

## 如果还是看不到

### 检查步骤

**1. 检查Flask日志**
启动Flask时查看日志输出，确认没有导入错误。

**2. 检查浏览器缓存**
```
Ctrl + Shift + R (强制刷新)
或清除浏览器缓存
```

**3. 检查Flask进程**
```cmd
netstat -ano | findstr ":5000"
```
确保只有一个Flask进程在运行。

**4. 运行验证脚本**
```cmd
test_port_conflict_discovery.bat
```
确认TestRunner能发现新用例。

**5. 检查目录结构**
```
test_cases/
└── port_conflict_tests/
    ├── __init__.py  ← 必须存在
    └── port_conflict_detection_test.py
```

## 技术细节

### TestRunner发现机制
1. 扫描`test_packages`列表中的所有包
2. 遍历每个包中的模块
3. 查找继承自`BaseTest`的类
4. 实例化并提取测试信息

### 分类推断逻辑
```python
if '/' in category:
    return category.split('/')[0]  # 取第一部分
else:
    return category  # 直接返回
```
