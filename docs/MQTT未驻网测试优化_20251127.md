## 问题背景

在执行未驻网测试用例时发现两个问题：

1. **SIM设置未恢复**: 测试完成后，蜂窝网络设置保持在"2G Only"模式，影响后续测试
2. **数据对比策略**: 未驻网测试的数据对比策略需要参照驻网测试，并且需要处理未注册状态下的特殊情况

---

## 修复内容

### 1. ✅ 测试完成后恢复SIM设置为Auto

**问题分析**:
- 测试用例在 `configure_cellular_unregistered()` 方法中将网络模式设置为 "2G Only"（第196行）
- 原来的 `cleanup()` 方法只断开MQTT连接，没有恢复蜂窝网络设置
- 这会导致路由器一直保持在2G模式，影响后续测试

**修复方案**:
- 在 `cleanup()` 方法中添加恢复步骤
- 新增 `restore_cellular_to_auto()` 方法，自动恢复网络模式为Auto
- 恢复步骤：
  1. 导航到蜂窝网络配置页面 `#network/interfaces/cellular`
  2. 点击配置按钮打开弹窗
  3. 选择 "Auto" 模式
  4. 点击OK按钮
  5. 点击保存应用按钮

**代码位置**: 第790-873行

```python
def cleanup(self):
    """测试清理"""
    try:
        # 1. 恢复SIM设置为Auto
        print("\n1. 恢复蜂窝网络设置为Auto...")
        if not self.restore_cellular_to_auto():
            print("  ⚠️  恢复蜂窝网络设置失败，请手动检查")
        else:
            print("  ✅ 蜂窝网络设置已恢复为Auto")

        # 2. 断开MQTT客户端连接
        if self.mqtt_client:
            print("\n2. 断开PC端MQTT客户端连接...")
            self.mqtt_client.disconnect()
            print("  ✅ MQTT客户端已断开")
    except Exception as e:
        print(f"清理资源失败: {e}")
        import traceback
        traceback.print_exc()
```

### 2. ✅ 优化数据对比策略

**问题分析**:
- 未注册状态下，很多字段可能是空值或特殊值（如 N/A, --, 0等）
- 如果严格按照驻网测试的对比策略，会导致测试失败
- 需要针对未注册状态添加特殊处理逻辑

**修复方案**:

#### 2.1 优化Modem数据验证 (verify_modem_data)

**代码位置**: 第610-688行

**优化内容**:
- ✅ 与驻网测试保持一致：移除RSRP、RSRQ、SINR三个实时变化字段
- ✅ 检测未注册状态：通过 `register` 字段判断是否为未注册状态
- ✅ 定义可选字段：未注册状态下允许以下字段为空
  - `net_provider` (ISP)
  - `net_type` (Network Type)
  - `band` (Cellular Frequency Band)
  - `plmnid` (PLMN ID)
  - `lac` (LAC)
  - `cellid` (Cell ID)
- ✅ 空值定义：支持多种空值表示 ('', 'n/a', '--', '0', 'none', 'null')
- ✅ 智能对比：
  - 如果MQTT和页面都为空 → 测试通过（正常）
  - 如果一个为空一个不为空 → 继续正常对比（异常情况）

```python
# 未注册状态下允许为空的字段
optional_fields_when_unregistered = [
    'net_provider', 'net_type', 'band', 'plmnid', 'lac', 'cellid'
]

# 先检查是否为未注册状态
register_status = str(modem_data.get('register', '')).strip().lower()
if 'unregistered' in register_status or 'not registered' in register_status:
    unregistered_state = True
    print(f"  ℹ️  检测到未注册状态，部分字段允许为空")
```

#### 2.2 优化Network数据验证 (verify_network_data)

**代码位置**: 第690-790行

**优化内容**:
- ✅ 与驻网测试保持一致：对比所有8个字段
  - status, ip, gate, dns (IPv4相关)
  - ipv6, gatev6, dnsv6 (IPv6相关)
  - time (连接时长)
- ✅ 检测APN断开状态：通过 `status` 字段判断APN是否断开
- ✅ 定义可选字段：APN断开时允许以下字段为空
  - `ip`, `gate`, `dns` (IPv4相关)
  - `ipv6`, `gatev6`, `dnsv6` (IPv6相关)
  - `time` (连接时长)
- ✅ 空值定义：支持多种空值表示 ('', 'n/a', '--', '0.0.0.0', '::', 'none', 'null')
- ✅ 智能对比：
  - 如果MQTT和页面都为空 → 测试通过（正常）
  - 如果一个为空一个不为空 → 继续正常对比（异常情况）

```python
# 检查当前APN是否断开
apn_status = str(vpn_data.get('status', '')).strip().lower()
apn_disconnected = apn_status in ['disconnected', 'disconnect', '']

# 断开状态下允许为空的字段
optional_fields_when_disconnected = [
    'ip', 'gate', 'dns', 'ipv6', 'gatev6', 'dnsv6', 'time'
]

# 特殊处理：APN断开时，允许连接相关字段为空
if apn_disconnected and mqtt_field in optional_fields_when_disconnected:
    empty_values = ['', 'n/a', '--', '0.0.0.0', '::', 'none', 'null']
    mqtt_is_empty = mqtt_value.lower() in empty_values
    page_is_empty = page_value.lower() in empty_values

    if mqtt_is_empty and page_is_empty:
        print(f"      ✓ {page_field}: APN断开，字段为空（正常）")
        continue
```

## 测试场景对比

### 驻网测试（ID 15）
- **网络状态**: 已注册，4G/5G网络连接
- **APN状态**: 至少一个APN已连接
- **字段值**: 所有字段都有有效值
- **对比策略**: 严格对比所有字段

### 未驻网测试（优化后）
- **网络状态**: 未注册或2G无信号
- **APN状态**: 所有APN断开
- **字段值**: 很多字段为空或特殊值
- **对比策略**:
  - ✅ 检测未注册状态，允许网络相关字段为空
  - ✅ 检测APN断开状态，允许连接相关字段为空
  - ✅ 对于必填字段（如IMEI、ICCID等），仍然严格对比

## 使用示例

### 正常执行流程

```bash
1. 测试开始
   → 配置蜂窝网络为2G Only（模拟未注册状态）

3. 数据对比

4. 测试清理
   → 恢复蜂窝网络设置为Auto ✅
   → 断开MQTT连接 ✅
   → 清理完成
```
