### 问题1: 测试用例不显示在Web界面
**原因**: category不匹配
- 测试用例返回: `"稳定性"`
- 前端期待: `"稳定性用例"`

**解决方案**:
```python
# test_cases/stability/multi_device_firmware_upgrade_stability_test.py
@property
def category(self) -> str:
    return "稳定性用例"  # 改为"稳定性用例"

# core/test_runner.py
elif 'stability' in package_name:
    return '稳定性用例'  # 改为"稳定性用例"
```

### 问题2: TestConfig初始化错误
**原因**: TestConfig是dataclass，需要必填参数

**解决方案**:
```python
if config is None:
    from models.test_config import TestMode
    config = TestConfig(
        router_config=RouterConfig(
            router_ip="192.168.50.17",
            username="admin",
            password="admin1",
            model="UR35"
        ),
        test_mode=TestMode.SPECIFIC
    )
```

### 问题3: 不能调用super().__init__()
**原因**: 这个测试用例管理多个设备，不能使用父类的单一router_client

**解决方案**:
- 手动初始化必要的属性
- 自己实现log_info等方法
- 不调用super().__init__()
