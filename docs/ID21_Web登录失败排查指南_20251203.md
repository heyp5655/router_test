## 🔍 排查步骤

### 第1步：检查串口日志

**查看串口日志文件**：
```
logs/serial/COM7_YYYYMMDD_HHMMSS.log
logs/serial/COM8_YYYYMMDD_HHMMSS.log
```

**关键检查点**：

#### 1.1 步骤7 - 串口登录是否成功？
```
[时间] [RECV] root@ROUTER:~#   ← 应该看到这个提示符
```

#### 1.2 步骤8 - ifconfig命令是否执行？
```
[时间] [SEND] ifconfig Bridge0 192.168.3.7
[时间] [RECV] root@ROUTER:~#
```

#### 1.3 步骤8 - IP配置是否成功？
```
[时间] [SEND] ifconfig Bridge0
[时间] [RECV] Bridge0    Link encap:Ethernet  HWaddr ...
[时间] [RECV]           inet addr:192.168.3.7  Bcast:...  Mask:255.255.255.0
                                   ^^^^^^^^^^^^^^  ← 应该是这个IP
[时间] [RECV]           UP BROADCAST RUNNING MULTICAST  MTU:1500  Metric:1
```

**如果看不到192.168.3.7**：
- 说明IP配置命令没有成功执行
- 可能原因：串口未登录、命令语法错误、权限不足

---

### 第2步：检查Web登录错误

**查看主控制台输出**：
```
步骤9: 等待IP生效和Web服务启动...
  等待IP配置生效...
  等待Web服务启动...
  尝试Web登录 192.168.3.7...
```

**可能的错误**：

#### 2.1 连接超时
```
❌ 错误: TimeoutException: Message: ...
```
**原因**：
- IP配置失败，路由器不在192.168.3.7
- 网络不通（路由器和PC不在同一网段）
- Web服务还没启动

**解决**：
- 检查串口日志确认IP配置成功
- 手动ping 192.168.3.7 测试连通性
- 增加等待时间到60秒

#### 2.2 页面加载失败
```
❌ 错误: WebDriverException: net::ERR_CONNECTION_REFUSED
```
**原因**：
- 路由器Web服务还没启动
- 路由器升级后Web服务异常

**解决**：
- 增加等待时间
- 手动浏览器访问 http://192.168.3.7 测试

#### 2.3 登录元素找不到
```
❌ 错误: NoSuchElementException: Unable to locate element: //input[@id='username']
```
**原因**：
- 页面结构改变
- 跳转到错误页面

**解决**：
- 手动访问查看页面
- 检查是否需要处理初始化向导

### 方案2：添加重试机制

**在步骤9添加重试**：
```python
# 步骤9: 重试登录（最多3次）
max_retries = 3
for retry in range(1, max_retries + 1):
    log_func(f"  尝试Web登录 {web_client.router_ip} ({retry}/{max_retries})...")

    try:
        if web_client.login_web_force():
            log_func(f"✅ Web重新登录成功")
            break
    except Exception as e:
        log_func(f"  ⚠️ 登录失败: {e}")
        if retry < max_retries:
            log_func(f"  等待10秒后重试...")
            time.sleep(10)
        else:
            raise Exception("升级后Web重新登录失败（已重试3次）")
```

---

### 方案3：验证IP配置成功

**在步骤8后验证IP**：
```python
# 步骤8: 配置并验证IP
serial_client.send_command("ifconfig Bridge0 192.168.3.7")
time.sleep(2)

# 读取IP验证
output = serial_client.send_command("ifconfig Bridge0")
if bridge_ip not in output:
    raise Exception(f"IP配置失败，未检测到 {bridge_ip}")
```

---

### 方案4：使用ping测试连通性

**在步骤9登录前先ping**：
```python
# 步骤9: 测试连通性后再登录
import subprocess

log_func(f"  测试网络连通性...")
try:
    # Windows: ping -n 3 192.168.3.7
    result = subprocess.run(
        ["ping", "-n", "3", bridge_ip],
        capture_output=True,
        text=True,
        timeout=10
    )
    if result.returncode == 0:
        log_func(f"  ✅ 网络连通正常")
    else:
        log_func(f"  ⚠️ 网络不通，但继续尝试登录...")
except Exception as e:
    log_func(f"  ⚠️ ping测试失败: {e}")

log_func(f"  尝试Web登录 {web_client.router_ip}...")
```
