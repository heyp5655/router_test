# DMVPN配置工具 - 快速入门指南

## 🚀 5分钟快速配置DMVPN

本指南将帮助您在5分钟内完成DMVPN服务器的可视化配置。

---

## 📋 前提条件

- ✅ Windows 10操作系统
- ✅ Python 3.x已安装
- ✅ 能SSH访问到DMVPN服务器
- ✅ 知道路由器支持的加密算法

---

## 🎯 步骤1: 启动工具 (30秒)

### 方法A: 双击启动（推荐）
双击项目根目录的 `启动DMVPN配置工具.bat`

### 方法B: 命令行启动
```bash
cd E:\GIT\ROUTER_TEST
python scripts\vpn_tools\dmvpn_config_gui.py
```

## 🔧 步骤2: 配置SSH连接 (1分钟)

在工具界面顶部填写：

| 参数 | 填写内容 | 示例 |
|------|----------|------|
| 服务器IP | DMVPN服务器的IP地址 | 192.168.50.48 |
| 端口 | SSH端口 | 22 |
| 用户名 | SSH登录用户名 | yuxy |
| 密码 | SSH登录密码 | milesight123 |

点击 **"测试连接"** 按钮，确认连接成功。

---

## ⚙️ 步骤3: 填写配置参数 (2分钟)

### 基础配置
- ✅ 启用：勾选
- Hub地址：`192.168.50.48` (内网) 或 `112.48.19.183` (公网)
- 接口：`WAN`

### GRE隧道配置
- GRE HUB IP地址：`10.0.0.1`
- GRE本地IP地址：`10.0.0.2`
- GRE子网掩码：`255.255.255.0`
- GRE密钥：`123456`

### IPSec Phase 1配置
- 协商模式：`Main`
- 加密算法：`AES256` (推荐) 或根据路由器支持选择
- 认证算法：`SHA2-256` (推荐)
- DH组：`MODP3072-15` (推荐) 或 `MODP2048-14` (兼容性好)

### IPSec Phase 2配置
- PSK密钥：`123456` (建议改为强密码)
- 本地ID类型：`Default`
- IKE生存时间：`10800`
- SA算法：`AES256-SHA2-256` (推荐)
- PFS组：`NULL`
- 生存时间：`3600`

### 高级配置
- DPD时间间隔：`30`
- DPD超时时间：`150`
- NHRP保持时间：`7200`
- ✅ 启用NAT穿透：勾选（如果服务器在NAT后面）

## ⚠️ 常见错误处理

### 错误1: SSH连接失败
**原因**: 服务器IP/密码错误，或防火墙阻止
**解决**:
- 检查IP和密码
- 确认SSH服务运行：`systemctl status ssh`
- 检查防火墙开放22端口

### 错误2: 配置应用后路由器无法连接
**原因**: 路由器和服务器参数不匹配
**解决**:
1. 点击"查看当前配置"检查服务器配置
2. 确认路由器配置与服务器一致
3. 特别检查：加密算法、DH组、PSK密钥、GRE密钥

### 错误3: Racoon服务启动失败
**原因**: 配置文件语法错误
**解决**:
1. SSH到服务器查看日志：`sudo tail -f /var/log/syslog | grep racoon`
2. 使用备份恢复配置
3. 重新应用配置

1. 启动工具
2. 连接SSH

## ✨ 小贴士

1. **首次配置**: 建议使用推荐配置，测试成功后再调整
2. **修改配置**: 每次应用配置前会自动备份，可放心修改

5. **兼容性**: 如果连接失败，尝试降低加密算法等级
