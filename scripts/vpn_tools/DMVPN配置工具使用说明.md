# DMVPN配置工具 - 使用说明

## 📋 工具简介

**DMVPN配置工具 v2.1 (dmvpn_config_gui.py)** 是一个可视化的图形界面工具，专注于配置DMVPN服务器端（Racoon + GRE隧道）。

### 主要功能
- ✅ 可视化界面配置所有服务器端DMVPN参数
- ✅ 支持路由器IP白名单管理（或允许任意IP）
- ✅ 支持所有主流加密算法和DH组
- ✅ 一键应用配置到远程服务器
- ✅ 自动备份现有配置
- ✅ 实时日志输出
- ✅ 配置验证和服务监控
- ✅ 无CMD窗口启动（pythonw）
- ✅ **完整滚动支持，所有区域可访问** ⭐ v2.1新增
- ✅ **鼠标滚轮流畅滚动** ⭐ v2.1新增
- ✅ **窗口大小自适应** ⭐ v2.1新增

## 🚀 快速开始

### 1. 安装依赖

在Windows 10命令提示符或PowerShell中运行：

```bash
pip install paramiko
```

**注意**: tkinter是Python内置库，无需额外安装。

### 2. 启动工具

**方式A: 双击启动（推荐）**
双击项目根目录的 `启动DMVPN配置工具.bat`，工具会在后台启动（无CMD窗口）。

**方式B: 带环境检查启动**
双击 `启动DMVPN配置工具_带检查.bat`，会先检查Python和依赖库，然后启动。

**方式C: 调试启动**
如果启动失败，使用 `启动DMVPN配置工具_调试版.bat` 查看详细错误。

**方式D: 命令行启动**
```bash
python scripts/vpn_tools/dmvpn_config_gui.py
```

### 3. 配置SSH连接

在工具界面中填写：
- **服务器IP**: DMVPN服务器的IP地址（默认: 192.168.50.48）
- **端口**: SSH端口（默认: 22）
- **用户名**: SSH登录用户名（默认: yuxy）
- **密码**: SSH登录密码

点击 **"测试连接"** 按钮验证连接是否正常。

### 2. 路由器IP配置（服务器端）

**两种工作模式**:

#### 模式A: 允许任意IP（推荐）
- ✅ 勾选 "允许任意IP (推荐)"
- 服务器接受来自任何IP的路由器连接（anonymous模式）
- 适用于4G路由器（公网IP不固定）或测试环境

#### 模式B: 限制特定IP
- ❌ 取消勾选 "允许任意IP"
- 在输入框填写路由器的WAN口IP
- 点击 "添加" 按钮
- 服务器只接受列表中的IP连接

**提示**：
- 填写路由器的**WAN口IP**（不是LAN口IP）
- 如果是4G路由器，填写公网IP
- 默认已添加: 192.168.50.16, 192.168.40.207, 10.33.126.188

---

### 3. GRE隧道配置（服务器端）

| 参数 | 说明 | 示例 |
|------|------|------|
| **服务器GRE IP** | 服务器在GRE隧道中的IP | 10.0.0.1 |
| **GRE子网掩码** | GRE隧道子网掩码 | 255.255.255.0 |
| **GRE密钥** | GRE隧道加密密钥 | 123456 |

**说明**：
- 服务器作为Hub，通常使用网段的第一个IP（如10.0.0.1）
- 路由器（Spoke）使用同一网段的其他IP（如10.0.0.2）
- **路由器端需要配置相同的GRE密钥**

---

### 4. IPSec Phase 1配置（服务器端）

| 参数 | 可选值 | 推荐值 |
|------|--------|--------|
| **加密算法** | AES256 / AES192 / AES128 / 3DES / DES / BLOWFISH | AES256 |
| **认证算法** | SHA2-256 / SHA2-384 / SHA2-512 / SHA1 / MD5 | SHA2-256 |
| **DH组** | MODP2048-14 / MODP3072-15 / MODP4096-16 等 | MODP3072-15 |

**重要**: 路由器端必须配置**完全相同**的加密算法、认证算法和DH组。

#### 加密算法说明

- **AES256**: 最安全，性能稍低（推荐生产环境）
- **AES192**: 平衡安全性和性能
- **AES128**: 性能最好，兼容性最强
- **3DES**: 传统算法，逐渐淘汰
- **DES**: 不安全，不推荐使用
- **BLOWFISH**: 快速加密，部分设备支持

#### DH组说明

- **MODP2048-14**: DH Group 14，兼容性好
- **MODP3072-15**: DH Group 15，安全性高（推荐）
- **MODP4096-16**: DH Group 16，最安全但速度慢
- **ECP256-19**: 椭圆曲线，高效安全
- **ECP384-20**: 椭圆曲线，更高安全性

### 5. IPSec Phase 2配置（服务器端）

| 参数 | 说明 | 示例 |
|------|------|------|
| **PSK密钥** | 预共享密钥（可点击"显示密钥"查看） | 123456 |
| **SA算法** | Phase 2加密和认证算法组合 | AES256-SHA2-256 |
| **PFS组** | Perfect Forward Secrecy组 | NULL |

**重要**: 路由器端必须配置**相同的PSK密钥**。

#### SA算法组合

格式: `加密算法-认证算法`

**常用组合**:
- `AES256-SHA2-256`: 高安全性（推荐）
- `AES128-SHA1`: 高兼容性
- `3DES-SHA1`: 传统组合

---

### 6. 高级配置（服务器端）

| 参数 | 说明 | 默认值 |
|------|------|--------|
| **启用NAT穿透** | 服务器在NAT后面必须启用 | ✅ 启用 |
| **IKE生存时间** | IKE SA生存时间（秒） | 10800 (3小时) |
| **SA生存时间** | IPSec SA生存时间（秒） | 3600 (1小时) |
| **DPD间隔** | Dead Peer Detection检测间隔 | 30秒 |

## 🔧 使用流程

### 标准配置流程

1. **填写SSH连接信息** → 点击"测试连接"
2. **配置路由器IP** → 允许任意IP 或 添加特定IP
3. **配置GRE隧道参数** → 服务器GRE IP、密钥等
4. **配置IPSec Phase 1** → 加密算法、DH组等
5. **配置IPSec Phase 2** → PSK密钥、SA算法等
6. **配置高级参数** → NAT穿透、生存时间等
7. **点击"应用配置到服务器"** → 自动备份并应用
8. **查看日志输出** → 确认配置成功
9. **在路由器Web界面配置相同参数** → 确保参数匹配

### 操作按钮说明

| 按钮 | 功能 |
|------|------|
| **测试连接** | 测试SSH连接是否正常 |
| **应用配置到服务器** | 将配置应用到服务器（自动备份原配置） |
| **重启Racoon服务** | 重启IPSec服务 |
| **查看当前配置** | 查看服务器当前的Racoon配置文件 |
| **清空日志** | 清空界面日志输出 |

## ⚠️ 注意事项

### 1. 安全建议
- ✅ 使用强PSK密钥（至少8位，包含字母数字）
- ✅ 生产环境使用AES256 + SHA2-256
- ✅ 使用MODP3072或更高的DH组
- ⚠️ 避免使用DES、MD5等弱算法

### 2. 兼容性
- 路由器端的加密算法必须与服务器端匹配
- 如果路由器不支持某个算法，选择兼容的较低版本
- DH组不匹配会导致Phase 1协商失败

### 3. NAT环境
- 服务器在NAT后面，必须启用NAT穿透
- NAT网关必须映射UDP 500和4500端口
- 建议使用标准端口映射（500→500, 4500→4500）

### 4. 配置备份
- 工具会自动备份配置文件到 `/etc/racoon/racoon.conf.bak.时间戳`
- 如需恢复，手动SSH到服务器执行恢复命令

### 5. 故障排查
- 应用配置后，查看日志确认服务状态
- 如果Racoon服务异常，点击"查看当前配置"检查语法
- 使用服务器端的诊断工具排查问题

## 🔍 常见问题

### Q1: 应用配置后路由器无法连接？
**A**: 检查以下几点：
1. 路由器和服务器的加密算法、DH组是否完全匹配
2. PSK密钥是否一致
3. GRE密钥是否一致
4. 路由器配置的Hub地址是否正确
5. NAT环境下是否启用NAT穿透
6. 如果限制特定IP，路由器的WAN IP是否在允许列表中

### Q2: SSH连接失败？
**A**: 检查：
1. 服务器IP是否正确
2. SSH服务是否运行：`sudo systemctl status ssh`
3. 防火墙是否开放22端口
4. 用户名密码是否正确

### Q3: 配置应用后Racoon服务异常？
**A**:
1. 点击"查看当前配置"检查配置文件
2. SSH到服务器查看日志：`sudo tail -f /var/log/syslog | grep racoon`
3. 检查配置参数是否有语法错误

### Q4: 如何恢复之前的配置？
**A**: SSH到服务器执行：
```bash
sudo cp /etc/racoon/racoon.conf.bak.时间戳 /etc/racoon/racoon.conf
sudo systemctl restart racoon
```

### Q5: 允许任意IP和限制特定IP有什么区别？
**A**:
- **允许任意IP（anonymous模式）**:
  - 服务器接受任何IP的路由器连接
  - 适用于4G路由器（公网IP不固定）
  - 配置简单，无需维护IP列表
  - 安全性相对较低

- **限制特定IP**:
  - 只接受列表中的路由器IP
  - 适用于固定IP的路由器
  - 安全性更高，生产环境推荐
  - 需要维护IP白名单

### Q6: 路由器应该配置什么参数？
**A**: 路由器端需要在Web界面配置以下参数，**必须与服务器端一致**：
- Hub地址: 服务器的IP地址
- GRE HUB IP: 10.0.0.1（服务器GRE IP）
- GRE本地IP: 10.0.0.2（或网段内其他IP）
- GRE密钥: 123456（与服务器相同）
- 加密算法: AES256（与服务器相同）
- 认证算法: SHA2-256（与服务器相同）
- DH组: MODP3072-15（与服务器相同）
- PSK密钥: 123456（与服务器相同）

## 📝 技术细节

### 生成的配置文件结构

```
/etc/racoon/racoon.conf  ← Racoon主配置文件
/etc/racoon/psk.txt      ← PSK密钥文件
```

### 工具执行流程

1. 连接SSH服务器
2. 备份现有配置文件
3. 根据界面参数生成新配置
4. 写入配置文件到服务器
5. 配置GRE隧道
6. 重启Racoon服务
7. 验证服务状态

### 支持的加密算法完整列表

**Phase 1 加密**:
- AES: 128/192/256 bit
- 3DES: 168 bit
- DES: 56 bit (不推荐)
- BLOWFISH: 448 bit

**Phase 1 认证**:
- SHA2: 256/384/512 bit
- SHA1: 160 bit
- MD5: 128 bit (不推荐)

**DH组**:
- MODP: 1024/1536/2048/3072/4096/6144/8192
- ECP (椭圆曲线): 256/384/521
